Bausteine: OB, FC, FB und DB

Wie ein SPS-Programm in Bausteine gegliedert wird: Organisationsbausteine (OB), Funktionen (FC), Funktionsbausteine (FB) mit Instanz-DB und Datenbausteine (DB). Die wichtigsten OBs und wie Bausteine in AWL aufgerufen werden.

Bausteinarten

BausteinWas er istEigener Speicher
OBOrganisationsbaustein. Wird vom Betriebssystem aufgerufen: Zyklus, Anlauf, Alarme oder FehlerTemporäre Daten (L)
FCFunktion. Code mit ParameternNein: nur temporäre Daten
FBFunktionsbaustein. Code mit Parametern und GedächtnisJa: ein Instanz-DB für jeden Aufruf
DBDatenbaustein (global oder Instanz)Er ist selbst Daten, immer remanent

OB35Weckalarm (standardmäßig alle 100 ms)

Tritt ein Fehler auf und ist der zugehörige Fehler-OB nicht geladen, geht die CPU in STOP.

AbschnittFCFBWofür

Aufrufe

// FC mit Parametern (AWL)
      CALL  FC     1
       Ein  :=E0.0
       Halt :=E0.1
       Motor:=A4.0

// FB mit seinem Instanz-DB
      CALL  FB     1 , DB     1
       Eingang:=E0.2
       Ausgang:=A4.1

// FC ohne Parameter
      UC    FC     2              // unbedingter Aufruf
      U     E      0.3
      CC    FC     3              // bedingter Aufruf: nur wenn VKE = 1

So sieht eine allgemeine FC in einer AWL-Quelle aus (eine Textdatei mit den Bausteinen; die Anweisungen enden mit ;):

FUNCTION FC 1 : VOID
TITLE = Allgemeines Ein/Aus
VAR_INPUT
  Ein : BOOL ;
  Halt : BOOL ;
END_VAR
VAR_IN_OUT
  Motor : BOOL ;
END_VAR
BEGIN
NETWORK
TITLE = Selbsthaltung
      U(    ;
      O     #Ein;
      O     #Motor;
      )     ;
      U     #Halt;
      =     #Motor;
END_FUNCTION

In KOP ist ein Aufruf eine Box mit EN/ENO, und die Parameter sind ihre Anschlüsse.

Häufige Fragen

Was ist der Unterschied zwischen einer FC und einem FB?

Der FB hat ein eigenes Gedächtnis: einen Instanz-DB, in dem er seine statischen Variablen (STAT) speichert, die ihren Wert zwischen zwei Aufrufen behalten. Eine FC hat nur temporäre Variablen, die am Ende verloren gehen.

Welcher OB bearbeitet das Hauptprogramm?

Der OB1, den die CPU zyklisch bearbeitet. Der OB100 ist der Anlauf, der OB35 der Weckalarm und der OB80 der Zeitfehler.

Was passiert, wenn ein Fehler auftritt und sein OB nicht programmiert ist?

Die CPU geht in STOP. Ein ungültiges BCD ruft zum Beispiel den OB121 auf: Ist der OB121 nicht geladen, hält die CPU an.
