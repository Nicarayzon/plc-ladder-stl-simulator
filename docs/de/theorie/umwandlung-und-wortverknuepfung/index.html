Umwandlung und Wortverknüpfung: BCD, INT, DINT und REAL

Wie man in AWL und KOP zwischen BCD, INT, DINT und REAL umwandelt, wie gerundet wird, wie ein Analogeingang in Prozent skaliert wird und wie Bits mit Wortverknüpfungen maskiert und geschoben werden.

Typische Analogwertskalierung (0..27648 → 0..100 %):

      L     PEW 256         // Rohwert (INT)
      ITD                   // INT → DINT
      DTR                   // DINT → REAL
      L     2.764800e+004
      /R
      L     1.000000e+002
      *R
      T     MD 60           // % als REAL

Wortverknüpfung und Schieben

AnweisungWirkung
UW, OW, XOWAKKU1-L := AKKU1-L (UND / ODER / Exklusiv-ODER) AKKU2-L. Mit einer Konstanten (UW W#16#00FF) wird mit der Konstanten verknüpft
UD, OD, XODDasselbe mit 32 Bit
SLW n / SRW nSchiebt AKKU1-L um n Bits nach links / rechts und füllt mit 0 auf
SSI nSchiebt AKKU1-L nach rechts und behält das Vorzeichen
SLD n / SRD n / SSD nSchieben mit 32 Bit
RLD n / RRD nRotiert AKKU1 um n Bits nach links / rechts
RLDA / RRDARotiert 1 Bit über A1
  • Ohne Operand wird die Anzahl der Stellen aus AKKU2-LL genommen.
  • Nach einer Wortverknüpfung: A1 = (Ergebnis ≠ 0), A0 = 0 und OV = 0.
  • Nach dem Schieben: A1 = zuletzt hinausgeschobenes Bit.

Beispiel: das niederwertige Byte eines Wortes ausblenden mit L MW 10 / UW W#16#00FF / T MW 12.

Häufige Fragen

Wie skaliere ich einen Analogeingang in Prozent?

Wandle den Wert in REAL um (ITD und DTR), teile ihn durch 27648 und multipliziere ihn mit 100. Mit 13824 am Eingang ergibt sich 50,0 %.

Was ist der Unterschied zwischen RND und TRUNC?

RND rundet auf die nächste Ganzzahl (3,6 → 4), und TRUNC schneidet die Nachkommastellen in Richtung 0 ab (3,6 → 3). RND+ rundet auf und RND- rundet ab.

Warum hinterlässt L MW 10 mit MW10 = −1 nicht −1 im 32-Bit-Akku?

Weil L den höherwertigen Teil mit Nullen füllt, ohne das Vorzeichen zu erweitern: AKKU1 ist dann DW#16#0000FFFF. Um den Wert als negatives DINT zu behandeln, verwendet man ITD.
