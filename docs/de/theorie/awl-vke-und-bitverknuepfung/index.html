AWL (Anweisungsliste) Schritt für Schritt: U, UN, O, ON, X und das VKE

Die Verknüpfungsanweisungen der AWL einzeln erklärt: U, UN, O, ON, X, XN, =, S, R und NOT, wie das VKE berechnet wird, wie man mit Klammern gruppiert und wie man eine Aufgabe von Hand löst, mit Beispielen zum Ausprobieren.

Wie man ein AWL-Programm liest

In AWL wird das Programm als Text geschrieben, eine Anweisung pro Zeile. Jede Zeile hat eine Operation und fast immer einen Operanden:

ZeileOperationOperandGelesen als
U E 0.0U (UND)E 0.0„und Eingang 0.0“
UN E 0.1UN (UND NICHT)E 0.1„und nicht Eingang 0.1“
= A 4.0= (zuweisen)A 4.0„das Ergebnis an Ausgang 4.0“

Die CPU bearbeitet die Zeilen von oben nach unten. Die Verknüpfungsanweisungen berechnen nach und nach ein Ergebnis, das VKE (Verknüpfungsergebnis), das dem „Strom“ in KOP entspricht: Jede Anweisung verknüpft das VKE mit ihrem Operanden, und am Ende schreibt = es in einen Ausgang.

Beispiel, Zeile für Zeile, mit E 0.0 = 1 und E 0.1 = 0:

AnweisungWas sie machtVKE danach
U E 0.0Erste Anweisung der Kette: kopiert E 0.01
U E 0.11 UND 00
= A 4.0Schreibt das VKE in A 4.0A 4.0 = 0

Die erste Verknüpfungsanweisung nach einer Zuweisung verknüpft nichts: Sie kopiert ihren Operanden ins VKE. Das ist die „Erstabfrage“ (siehe Bitverknüpfung: VKE, Erstabfrage und STA).

U: UND

U bedeutet „und außerdem ist dieses Bit 1“. Es verknüpft das VKE mit dem Operanden über ein UND: Das Ergebnis bleibt nur 1, wenn der Operand 1 ist.

  • In KOP entspricht das einem Schließer in Reihe.
  • Mehrere U hintereinander: Das Ergebnis ist nur 1, wenn alle erfüllt sind.
      U     E 0.0
      U     E 0.1           // und außerdem E0.1
      =     A 4.0           // A4.0 = E0.0 ∧ E0.1

UN: UND NICHT

UN bedeutet „und außerdem ist dieses Bit 0“. Es ist ein UND mit negiertem Operanden: VKE := VKE ∧ ¬Operand.

  • In KOP entspricht das einem Öffner in Reihe.
  • So schreibt man Bedingungen wie „Ein und kein Alarm“:
      U     E 0.0           // Ein
      UN    E 0.1           // und kein Alarm
      =     A 4.0           // A4.0 = E0.0 ∧ ¬E0.1

O: ODER

O bedeutet „oder dieses Bit ist 1“. Es verknüpft das VKE mit dem Operanden über ein ODER: Das Ergebnis ist 1, wenn irgendeine der Bedingungen erfüllt ist.

  • In KOP entspricht das einem Schließer parallel.
  • Bei einer Parallelschaltung einzelner Kontakte schreibt man auch in die erste Zeile O (O E 0.0 / O E 0.1), obwohl U E 0.0 / O E 0.1 dasselbe ergäbe: Die erste Anweisung kopiert nur den Operanden.
      O     E 0.0
      O     E 0.1           // oder E0.1
      =     A 4.0           // A4.0 = E0.0 ∨ E0.1

ON: ODER NICHT

ON bedeutet „oder dieses Bit ist 0“: VKE := VKE ∨ ¬Operand. In KOP entspricht das einem Öffner parallel.

      O     E 0.0
      ON    E 0.1           // oder E0.1 ist 0
      =     A 4.0           // A4.0 = E0.0 ∨ ¬E0.1

X und XN: Exklusiv-ODER

X ist das Exklusiv-ODER: Das Ergebnis ist 1, wenn nur einer der beiden 1 ist, und 0, wenn beide gleich sind. XN ist das Gegenteil: 1, wenn beide gleich sind.

E 0.0E 0.1X E 0.0 / X E 0.1X E 0.0 / XN E 0.1
0001
0110
1010
1101

Eine typische Anwendung ist die Wechselschaltung im Flur: zwei Schalter, einer an jedem Ende, und jeder von beiden wechselt den Zustand des Lichts. In KOP gibt es keinen Exklusiv-ODER-Kontakt: Man zeichnet es mit zwei Zweigen (siehe Verknüpfungen mit Kontakten), wie in diesem Netzwerk.

      X     E 0.0           // Schalter am einen Ende des Flurs
      X     E 0.1           // Schalter am anderen Ende
      =     A 4.0           // jeder der beiden Schalter wechselt das Licht

=, S und R: das Ergebnis schreiben

Wenn die Verknüpfung berechnet ist, muss das VKE irgendwohin geschrieben werden:

AnweisungWas sie machtIn KOP
= A 4.0A 4.0 := VKE, immer (1 oder 0)Spule
S A 4.0Wenn VKE = 1, A 4.0 := 1. Bei VKE = 0 passiert nichtsSpule
R A 4.0Wenn VKE = 1, A 4.0 := 0. Bei VKE = 0 passiert nichtsSpule
  • Nach =, S oder R ist die Kette abgeschlossen: Das nächste U oder O beginnt eine neue Verknüpfung.
  • Man kann mehrere = hintereinander schreiben, um dasselbe Ergebnis mehreren Ausgängen zuzuweisen.
  • Mit S und R „merkt“ sich das Bit seinen Wert. Probiere es aus: Ein Impuls an E 0.0 schaltet A 4.0 ein, das nach dem Loslassen von E 0.0 eingeschaltet bleibt, bis E 0.1 es ausschaltet.
      U     E 0.0
      S     A 4.0           // wenn E0.0 = 1, wird A4.0 gesetzt und bleibt 1
      U     E 0.1
      R     A 4.0           // wenn E0.1 = 1, wird A4.0 wieder 0

NOT, SET und CLR

Diese drei Anweisungen haben keinen Operanden und wirken direkt auf das VKE:

AnweisungWas sie machtAnwendungsbeispiel
NOTNegiert das VKEU E 0.0 / U E 0.1 / NOT / = A 4.0 ist ein NAND
SETSetzt das VKE auf 1Eine feste 1 schreiben: SET / = M 0.0
CLRSetzt das VKE auf 0Eine feste 0 schreiben: CLR / = M 0.0

Vorsicht mit SET: Es setzt keinen Operanden auf 1, sondern nur das VKE. Um ein Bit zu setzen, verwendet man S.

Format

  • Eine Anweisung pro Zeile. Der Code ist wie in KOP in Netzwerke gegliedert.
  • Sprungziele (Marken): bis zu 4 Zeichen, beginnen mit einem Buchstaben und enden mit :.
  • Kommentare beginnen mit //. In AWL-Quellen endet jede Anweisung mit ;.
  • Leerzeichen zwischen Bereich und Adresse spielen keine Rolle: E 0.0 ist dasselbe wie E0.0.

Bitverknüpfung: VKE, Erstabfrage und STA

Jede Verknüpfungsanweisung verknüpft das aktuelle VKE mit dem Bit des Operanden:

AnweisungWenn /ER = 0 (Erstabfrage)Wenn /ER = 1 (Kette läuft)
U op (UND)VKE := opVKE := VKE ∧ op
UN op (UND NICHT)VKE := ¬opVKE := VKE ∧ ¬op
O op (ODER)VKE := opVKE := VKE ∨ op
ON op (ODER NICHT)VKE := ¬opVKE := VKE ∨ ¬op
X op (Exklusiv-ODER)VKE := opVKE := VKE ⊕ op
XN op (Exklusiv-ODER NICHT)VKE := ¬opVKE := VKE ⊕ ¬op

Nach jeder von ihnen gilt: /ER := 1 und STA := Wert des Operanden.

Anweisungen, die die Kette abschließen (/ER := 0), ohne das VKE zu ändern:

  • =, S und R.
  • Die Zeitoperationen (SI, SV, SE, SS, SA, R T, FR T).
  • Die Zähloperationen (ZV, ZR, S Z, R Z).

Deshalb lassen sich mehrere Zuweisungen mit demselben VKE aneinanderreihen:

      U     E 0.0
      U     E 0.1
      =     A 4.0      // A4.0 := E0.0 ∧ E0.1
      =     A 4.1      // A4.1 bekommt dasselbe VKE
      S     M 0.0      // und setzt auch M0.0, wenn es 1 ist

Anweisungen, die VKE und /ER NICHT verändern: L, T, Arithmetik, Umwandlung, TAK, INC, DEC... Eine Verknüpfungskette kann „über sie hinweg“ weiterlaufen:

      U     E 0.0
      L     MW 10      // ändert das VKE nicht
      T     MW 12      // wird IMMER ausgeführt (T hängt nicht vom VKE ab)
      =     A 4.0      // A4.0 := E0.0

Operationen direkt auf das VKE:

AnweisungWirkung
NOTVKE := ¬VKE
SETVKE := 1 (und /ER := 0)
CLRVKE := 0 (und /ER := 0)
SAVEBIE := VKE

„UND vor ODER“: O ohne Operand und Klammern

AWL wertet der Reihe nach aus: U E0.0 / O E0.1 / U E0.2 berechnet (E0.0 ∨ E0.1) ∧ E0.2 und nicht E0.0 ∨ (E0.1 ∧ E0.2). Zum Gruppieren gibt es zwei Werkzeuge.

a) O ohne Operand trennt UND-Gruppen, die mit ODER verknüpft werden:

      U     E 0.0
      U     E 0.1
      O                 // (E0.0 ∧ E0.1)  ∨ ...
      U     E 0.2
      U     E 0.3
      =     A 4.0       // A4.0 = (E0.0 ∧ E0.1) ∨ (E0.2 ∧ E0.3)

Was intern passiert: O speichert das Ergebnis der ersten Gruppe im Bit OR und setzt /ER = 0. Solange OR = 1 ist, lassen die folgenden U und UN das VKE auf 1, weil das Ergebnis schon feststeht. = setzt OR := 0.

b) Klammern: U(, UN(, O(, ON(, X(, XN( ... ).

      U     E 0.0
      U(                // E0.0 ∧ ( ... )
      O     E 0.1
      O     E 0.2
      )
      =     A 4.1       // A4.1 = E0.0 ∧ (E0.1 ∨ E0.2)
  • Beim Öffnen der Klammer werden das VKE, das Bit OR und die ausstehende Verknüpfung im Klammerstack gespeichert, und eine neue Kette beginnt (/ER = 0).
  • Beim Schließen mit ) wird das Gespeicherte zurückgeholt und mit dem VKE aus der Klammer verknüpft.
  • Es sind bis zu 7 Klammerebenen erlaubt.

Statusbits als Operanden

U OV, U OS, U BIE, U ==0, U <>0, U >0, U <0, U >=0, U <=0 und U UO (ungeordnet). Sie funktionieren auch mit UN, O, ON, X und XN.

      L     MW 40
      L     MW 42

Zustandstabelle (Aufgaben von Hand lösen)

Man notiert Zeile für Zeile den Zustand von /ER, VKE, STA und OR. Beispiel mit E0.0 = 1, E0.1 = 0, E0.2 = 1 und E0.3 = 1:

Anweisung/ER vorherSTAVKE nachherORKommentar

U E 0.110001 ∧ 0
O1100OR := VKE (0); /ER := 0
U E 0.20110Erstabfrage der 2. Gruppe
U E 0.311101 ∧ 1
= A 4.01110A4.0 = 1; /ER := 0 (STA = geschriebener Wert)

Mit E0.0 = E0.1 = 1 und E0.2 = E0.3 = 0: Nach O ist das Bit OR = 1. Die beiden folgenden U lassen das VKE auf 1, deshalb ist A4.0 = 1.

Teste dein Wissen

Überlege dir die Antwort, bevor du die Lösung aufklappst.

Q01AWL wird der Reihe nach ausgewertet

Mit E0.0 = 1, E0.1 = 0 und E0.2 = 0: Welchen Wert hat A4.0?

      U     E 0.0
      O     E 0.1
      U     E 0.2
      =     A 4.0
Lösung

A4.0 = 0. Berechnet wird (E0.0 ∨ E0.1) ∧ E0.2 = (1 ∨ 0) ∧ 0 = 0, nicht 1 ∨ (0 ∧ 0).

Q02O ohne Operand

Dieselben Eingänge wie in Q01. Welchen Wert hat A4.0?

      U     E 0.0
      O
      U     E 0.1
      U     E 0.2
      =     A 4.0
Lösung

A4.0 = 1. Berechnet wird E0.0 ∨ (E0.1 ∧ E0.2).

Häufige Fragen

Was ist das VKE in AWL?

Das Verknüpfungsergebnis: das Bit des Statusworts, in dem sich das Ergebnis der Verknüpfungsanweisungen (U, O, X…) aufbaut. Die Zuweisungen =, S und R schreiben es in einen Operanden.

Wofür ist das Bit /ER (Erstabfrage)?

Es zeigt an, ob die nächste Verknüpfungsanweisung eine neue Kette beginnt. Bei /ER = 0 kopiert das nächste U, O oder X den Operanden ins VKE, statt ihn damit zu verknüpfen.

Warum berechnet U a / O b / U c nicht „a oder (b und c)“?

Weil AWL der Reihe nach auswertet: Es berechnet (a ∨ b) ∧ c. Für a ∨ (b ∧ c) braucht man O ohne Operand oder Klammern.

Wie viele verschachtelte Klammern erlaubt AWL?

Sieben Ebenen. Werden sie überschritten, tritt ein Fehler auf und die CPU geht in STOP.

Was macht die Anweisung SET in AWL?

Sie setzt das VKE auf 1 und schließt die Verknüpfungskette ab (/ER = 0). Sie setzt keinen Operanden auf 1: Dafür gibt es S.
