Taktmerker: Blinklichter ohne Zeiten

Was der Taktmerker einer SPS ist, wie er aktiviert wird, mit welcher Frequenz jedes Bit schwingt und wie man damit eine Leuchte blinken lässt oder eine Aktion jede Sekunde wiederholt, mit Beispielen in KOP und AWL.

Taktmerker

Der Taktmerker ist ein Merkerbyte, das die CPU selbst schreibt: Jedes seiner 8 Bits schwingt mit einer festen Frequenz und ist die Hälfte der Periode 0 und die andere Hälfte 1. Damit lassen sich Leuchten blinken lassen und Aktionen in regelmäßigen Abständen wiederholen, ohne Zeiten zu programmieren.

So wird er aktiviert:

  • In der echten CPU: Eigenschaften der CPU → Zyklus/Taktmerker. Das Kästchen anhaken, das Byte wählen (zum Beispiel MB100) und die Hardwarekonfiguration laden.
  • Im Simulator: Schaltfläche Hardware → CPU → Ciclo / marca de ciclo (die Oberfläche ist auf Spanisch). Standardmäßig wird MB0 verwendet, aber jedes Byte kann gewählt werden.
Bit76543210
Periodendauer (s)2,01,61,00,80,50,40,20,1
Frequenz (Hz)0,50,62511,2522,5510

Mit MB100 als Taktmerker hat M 100.5 eine Periodendauer von 1 s: 0,5 s auf 0 und 0,5 s auf 1. Das heißt, er blinkt mit 1 Hz.

Typische Anwendungen:

  • Blinkleuchte: Der Taktmerker wird in Reihe mit der Bedingung geschaltet. U E 0.0 / U M 100.5 / = A 4.0 lässt A4.0 mit 1 Hz blinken, solange E0.0 = 1 ist.
  • Zwei Blinkrhythmen mit derselben Leuchte: langsam mit M 100.7 (0,5 Hz) für eine Warnung und schnell mit M 100.3 (2 Hz) für einen Alarm.
  • Periodische Aktion: M 100.5 liefert eine steigende Flanke pro Sekunde. Mit einem Zähler (ZV) zählt man Sekunden, und mit FP führt man etwas einmal pro Sekunde aus.

Achtung:

  • Das Programm darf dieses Byte nur lesen. Die CPU überschreibt es in jedem Zyklus, deshalb geht alles verloren, was das Programm hineinschreibt. Der Simulator warnt, wenn das Programm in dieses Byte schreibt.
  • Das Byte muss frei bleiben: Verwende es für nichts anderes, auch nicht als Teil eines Wortes (MW 99 und MW 100 enthalten MB 100).
  • Für genaue Zeitmessungen ist er nicht geeignet: Wenn die Bedingung erfüllt wird, kann das Bit mitten in seiner Periode stehen, deshalb kann das erste Blinken kürzer sein. Für genaue Verzögerungen verwendet man Zeiten (siehe Zeiten in KOP).
  • Im Simulator wird das Byte zu Beginn jedes Zyklus aktualisiert, bevor die Eingänge gelesen werden. Wird der Taktmerker deaktiviert oder das Byte geändert, wird das alte Byte auf 0 gesetzt.

Gelöste Beispiele

Blinkleuchte mit dem Taktmerker

Aufgabe: Solange der Alarm E0.0 ansteht, blinkt die Leuchte A4.0 mit 1 Hz. Der Taktmerker liegt in MB100, deshalb wird M 100.5 (Periodendauer 1 s) verwendet.

      U     E 0.0           // Alarm steht an
      U     M 100.5         // Taktmerker: 1 Hz
      =     A 4.0           // Blinkleuchte

Sekunden zählen mit dem Taktmerker

Aufgabe: Solange E0.3 = 1 ist, zählt Z2 bei jeder steigenden Flanke von M 100.5 um 1 hoch, also einmal pro Sekunde. E0.4 setzt ihn zurück, und MW40 enthält die gezählten Sekunden. Die erste Sekunde kann sofort gezählt werden: Das hängt davon ab, an welcher Stelle seiner Periode M 100.5 steht, wenn E0.3 eingeschaltet wird.

      U     E 0.3           // zählen, solange E0.3 = 1
      U     M 100.5         // eine steigende Flanke pro Sekunde
      ZV    Z 2
      U     E 0.4           // zurücksetzen
      R     Z 2
      L     Z 2
      T     MW 40           // gezählte Sekunden

Häufige Fragen

Welches Bit schwingt mit 1 Hz, wenn MB100 der Taktmerker ist?

M 100.5, das eine Periodendauer von 1 s hat. Die Periodendauern der Bits 0 bis 7 sind 0,1 / 0,2 / 0,4 / 0,5 / 0,8 / 1 / 1,6 / 2 s.

Darf ich in das Byte des Taktmerkers schreiben?

Nein: Die CPU überschreibt es in jedem Zyklus, deshalb geht alles verloren, was das Programm hineinschreibt. Das Programm darf es nur lesen.

Taktmerker oder Zeiten für ein Blinklicht?

Den Taktmerker, wenn dir eine seiner Frequenzen genügt und es egal ist, an welcher Stelle das Blinken beginnt. Zeiten, wenn du unterschiedliche Ein- und Auszeiten brauchst oder das Blinken genau beim Erfüllen der Bedingung beginnen muss (Beispiel E17).
