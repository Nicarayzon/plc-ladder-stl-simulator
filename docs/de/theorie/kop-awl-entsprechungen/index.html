Entsprechungen KOP ↔ AWL: von einer Sprache in die andere

Boxen mit EN/ENO

Wird eine Box mit EN in AWL übersetzt, erzeugt der Editor einen Sprung, der sie bei EN = 0 überspringt, und setzt BIE so, dass ENO anzeigt, ob ein Fehler aufgetreten ist. Vereinfachtes Schema von ADD_I mit EN:

      U     E 0.0           // EN
      SPBNB _001            // wenn EN = 0 → springen (und BIE := 0)
      L     MW 10
      L     MW 12
      +I
      T     MW 14
      UN    OV              // kein Überlauf…
      SAVE                  // …BIE := 1
      CLR
_001: U     BIE             // ENO = BIE
      =     A 4.0

Nicht jede AWL lässt sich in KOP umwandeln. Zum Beispiel: Sprünge innerhalb eines Netzwerks, Akkumulatoroperationen (TAK, ein einzelnes +I), indirekte Adressierung oder O ohne Operand an ungewöhnlichen Stellen. Diese Netzwerke bleiben in AWL.

Häufige Fragen

Lässt sich jedes AWL-Programm in KOP umwandeln?

Nein. Sprünge innerhalb eines Netzwerks, einzelne Akkumulatoroperationen, indirekte Adressierung oder O ohne Operand an ungewöhnlichen Stellen haben keine Darstellung in KOP, und diese Netzwerke bleiben in AWL. Umgekehrt schon: Jedes KOP hat seine AWL.

Wie schreibt man zwei parallele Kontakte in AWL?

Mit O a / O b. Stehen sie danach in Reihe mit einem weiteren Kontakt, kommt U c dazu: O a / O b / U c berechnet (a ∨ b) ∧ c.

Wie schaltet man in AWL einen Vergleich in Reihe mit einem Kontakt?

In Klammern: U E 2.0 / U( / L MW 30 / L 500 / >I / ).
