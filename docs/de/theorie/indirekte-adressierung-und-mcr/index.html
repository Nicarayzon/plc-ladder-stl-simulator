Indirekte Adressierung und MCR in AWL

Speicherindirekte und registerindirekte Adressierung in AWL, das Format des Bereichszeigers und das Master Control Relay (MCR), mit einem Beispiel, das eine Tabelle von Wörtern aufsummiert.

Indirekte Adressierung (fortgeschritten)

  • Speicherindirekt: Die Adresse steht in einem Merker oder einem Datum, im Zeigerformat. Zum Beispiel: L MW [MD 30] oder U E [MD 34].
  • Registerindirekt: LAR1 P#M 100.0 und danach L MW [AR1, P#2.0].
  • Format des Bereichszeigers (32 Bit): Bytenummer × 8 + Bitnummer. Zum Beispiel entspricht P#10.0 dem Wert 80.

Beispiel: MW100..MW118 mit einem Zeiger durchlaufen und aufsummieren.

      L     P#100.0
      T     MD 30           // Zeiger auf das erste Element
      L     0
      T     MW 40           // Summe = 0
      L     10              // 10 Elemente
SIG:  T     MW 34
      L     MW 40
      L     MW [MD 30]
      +I
      T     MW 40
      L     MD 30
      L     P#2.0           // nächstes Wort
      +D
      T     MD 30
      L     MW 34
      LOOP  SIG

MCR (Master Control Relay)

  • MCRA aktiviert den MCR-Bereich und MCRD deaktiviert ihn.
  • Innerhalb von MCR( … )MCR schreiben alle Zuweisungen = und alle Transfers T den Wert 0, wenn die Bedingung vor MCR( gleich 0 ist. S und R wirken dann nicht.
  • Es ersetzt keinen fest verdrahteten Not-Halt-Kreis.

Gelöste Beispiele

E29Tabelle mit indirekter Adressierung aufsummieren

Aufgabe: MW40 = Summe der 10 Wörter MW100, MW102, …, MW118.

Konzepte: Bereichszeiger (P#Byte.Bit = Byte × 8 + Bit), L MW [MD 30] und LOOP (siehe Indirekte Adressierung (fortgeschritten)). Gibt es nur in AWL: In KOP gibt es keine Darstellung dafür.

      L     P#100.0
      T     MD 30       // Zeiger auf das erste Element (100 × 8 = 800)
      L     0
      T     MW 40       // Summe = 0
      L     10          // 10 Elemente
SIG:  T     MW 34       // Schleifenzähler
      L     MW 40
      L     MW [MD 30]
      +I
      T     MW 40
      L     MD 30
      L     P#2.0       // ein Wort weiter (2 Bytes = 16)
      +D
      T     MD 30
      L     MW 34
      LOOP  SIG

Häufige Fragen

Was ist indirekte Adressierung in AWL?

Eine Adresse zu verwenden, die an anderer Stelle gespeichert ist, statt sie fest in den Code zu schreiben. Zum Beispiel lädt L MW [MD 30] das Wort, dessen Adresse in MD30 steht. Damit durchläuft man Tabellen in einer Schleife.

Wie berechnet man einen Zeiger P#?

Bytenummer × 8 + Bitnummer. P#10.0 ist 80 und P#2.0 ist 16: Deshalb rückt ein Zeiger um ein Wort weiter, wenn man P#2.0 addiert.

Ersetzt das MCR einen Not-Halt?

Nein. Das MCR bewirkt nur, dass in einem Bereich des Programms die Zuweisungen = und die Transfers T eine 0 schreiben. Ein Not-Halt muss getrennt verdrahtet werden, außerhalb des Programms.
