Conversiones y lógica de palabras: BCD, INT, DINT y REAL

Cómo convertir entre BCD, INT, DINT y REAL en AWL y en KOP, cómo redondear, cómo escalar una entrada analógica a porcentaje y cómo enmascarar y desplazar bits con la lógica de palabras.

Conversión

AWLKOPConversiónNotas
BTIBCD_IBCD de 3 cifras → INT (ACU1-L)Cifra no válida → error BCD (OB121)
ITBI_BCDINT → BCD de 3 cifrasFuera de ±999 → OV = OS = 1 y no convierte
BTDBCD_DIBCD de 7 cifras → DINT
DTBDI_BCDDINT → BCD de 7 cifras
ITDI_DIINT → DINT (extiende el signo)
DTRDI_RDINT → REALPor encima de 2²⁴ puede perder precisión
RNDROUNDREAL → DINT, redondeando al más próximoEn el caso exacto de x,5 el manual de AWL indica redondeo al par
TRUNCTRUNCREAL → DINT truncando hacia 03,9 → 3 ; −3,9 → −3
RND+CEILREAL → DINT hacia +∞3,2 → 4 ; −3,2 → −3
RND-FLOORREAL → DINT hacia −∞3,2 → 3 ; −3,2 → −4
INVI / INVDINV_I / INV_DIComplemento a 1 (invierte los bits)
NEGI / NEGDNEG_I / NEG_DIComplemento a 2 (cambia el signo)
NEGRNEG_RCambia el signo de un REAL
CAW—Intercambia los 2 bytes de ACU1-L
CAD—Invierte el orden de los 4 bytes de ACU1

Escalado analógico típico (0..27648 → 0..100 %):

      L     PEW 256         // valor bruto (INT)
      ITD                   // INT → DINT
      DTR                   // DINT → REAL
      L     2.764800e+004
      /R
      L     1.000000e+002
      *R
      T     MD 60           // % en REAL

Lógica de palabras y desplazamientos

InstrucciónEfecto
UW, OW, XOWACU1-L := ACU1-L (Y / O / O-exclusiva) ACU2-L. Si llevan constante (UW W#16#00FF), operan con la constante
UD, OD, XODLo mismo con 32 bits
SLW n / SRW nDesplaza ACU1-L n bits a la izquierda / derecha, rellenando con 0
SSI nDesplaza ACU1-L a la derecha manteniendo el signo
SLD n / SRD n / SSD nDesplazamientos de 32 bits
RLD n / RRD nRota ACU1 n bits a la izquierda / derecha
RLDA / RRDARota 1 bit pasando por A1
  • Sin operando, el número de posiciones se toma de ACU2-LL.
  • Tras la lógica de palabras: A1 = (resultado ≠ 0), A0 = 0 y OV = 0.
  • Tras un desplazamiento: A1 = último bit que ha salido.

Ejemplo: aislar el byte bajo de una palabra con L MW 10 / UW W#16#00FF / T MW 12.

Preguntas frecuentes

¿Cómo escalo una entrada analógica a porcentaje?

Convierte el valor a REAL (ITD y DTR), divide entre 27648 y multiplica por 100. Con 13824 en la entrada, el resultado es 50,0 %.

¿Qué diferencia hay entre RND y TRUNC?

RND redondea al entero más próximo (3,6 → 4) y TRUNC corta la parte decimal hacia 0 (3,6 → 3). RND+ redondea hacia arriba y RND- hacia abajo.

Con MW10 = −1, ¿por qué L MW 10 no deja −1 en el acumulador de 32 bits?

Porque L rellena con ceros la parte alta, sin extender el signo: ACU1 queda en DW#16#0000FFFF. Para tratarlo como DINT negativo hay que usar ITD.
