Marcha y paro: enclavamiento, Set y Reset en KOP y AWL

Cómo programar una marcha y paro en KOP y AWL: enclavamiento (autorretención), bobinas Set y Reset, biestables SR y RS, y cómo se decide la prioridad entre marcha y paro.

En KOP: bobinas, enclavamiento y biestables

Enclavamiento (autorretención) — marcha y paro con prioridad al paro:

Set/Reset con bobinas: el que se ejecuta el último tiene prioridad.

Cuadro SR / RS:

Una bobina por operando. Si el mismo bit tiene dos bobinas , solo vale la última. Las bobinas S y R del mismo bit sí pueden aparecer varias veces: es lo normal.

En AWL: asignación, Set y Reset

InstrucciónEfectoPrioridad
= opop := RLO, siempre—
S opsi RLO = 1 → op := 1 (si RLO = 0 no hace nada)—
R opsi RLO = 1 → op := 0—

Cuando un mismo bit tiene S y R, gana la que se ejecuta la última:

      U     E 0.0           // marcha
      S     A 4.0
      U     E 0.1           // paro
      R     A 4.0           // R al final → prioridad a desactivar (paro)

Ejemplos resueltos

E06Marcha y paro con enclavamiento (prioridad al paro)

Enunciado: E0.0 = marcha (pulsador NA). E0.1 = paro (pulsador NC cableado, así que vale 1 en reposo). A4.0 = motor.

Conceptos: autorretención, seguridad por cableado y prioridad al paro.

      U(
      O     E 0.0       // marcha
      O     A 4.0       // realimentación (enclavamiento)
      )
      U     E 0.1       // paro NC: 1 = no pulsado
      =     A 4.0

E07Marcha y paro con Set/Reset (prioridad al paro)

Conceptos: la prioridad la da el orden: la última instrucción gana.

      U     E 0.0
      S     A 4.0
      UN    E 0.1       // paro pulsado (E0.1 = 0)
      R     A 4.0       // R al final → prioridad al paro

E08Marcha y paro con prioridad a la marcha

Enunciado: igual que E07, pero si se pulsan los dos debe ganar la marcha.

      UN    E 0.1
      R     A 4.0
      U     E 0.0
      S     A 4.0

Preguntas frecuentes

¿Qué es un enclavamiento o autorretención?

Un circuito en el que la salida se mantiene encendida a través de su propio contacto: el pulsador de marcha la enciende y, al soltarlo, el contacto de la propia salida la mantiene hasta que se pulsa el paro.

Si un bit tiene Set y Reset activos a la vez, ¿cuál gana?

La instrucción que se ejecuta la última. Con el Reset detrás, gana el paro; con el Set detrás, gana la marcha. La prioridad la da el orden, no el tipo de bobina.

¿Qué instrucción AWL equivale a la bobina (S) de KOP?

S. No hay que confundirla con SET, que pone el RLO a 1, ni con SE, que arranca un temporizador.

¿Qué diferencia hay entre los biestables SR y RS?

Con las dos entradas a 1, el SR da prioridad al reset (Q = 0) y el RS al set (Q = 1).
