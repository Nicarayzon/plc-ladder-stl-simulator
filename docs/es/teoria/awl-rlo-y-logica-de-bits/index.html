AWL (STL) paso a paso: U, UN, O, ON, X y el RLO

Las instrucciones lógicas de AWL (STL) explicadas una a una: U, UN, O, ON, X, XN, =, S, R y NOT, cómo se calcula el RLO, cómo se agrupa con paréntesis y cómo resolver un ejercicio a mano, con ejemplos que puedes probar aquí mismo.

Cómo se lee un programa AWL

En AWL el programa se escribe en texto, con una instrucción por línea. Cada línea tiene una operación y, casi siempre, un operando:

LíneaOperaciónOperandoSe lee
U E 0.0U (Y)E 0.0«y la entrada 0.0»
UN E 0.1UN (Y no)E 0.1«y no la entrada 0.1»
= A 4.0= (asignar)A 4.0«el resultado, a la salida 4.0»

La CPU ejecuta las líneas de arriba abajo. Las instrucciones lógicas van calculando un resultado, el RLO (resultado lógico), que es lo mismo que la «corriente» de KOP: cada instrucción combina el RLO con su operando, y al final = lo escribe en una salida.

Ejemplo, línea a línea, con E 0.0 = 1 y E 0.1 = 0:

InstrucciónQué haceRLO después
U E 0.0Primera instrucción de la cadena: copia E 0.01
U E 0.11 Y 00
= A 4.0Escribe el RLO en A 4.0A 4.0 = 0

La primera instrucción lógica después de una asignación no combina nada: copia su operando en el RLO. Es la «primera consulta» (ver Lógica de bits: RLO, primera consulta y STA).

U: Y (AND)

U significa «y además este bit vale 1». Combina el RLO con el operando mediante una Y: el resultado solo sigue a 1 si el operando vale 1.

  • En KOP equivale a un contacto NA en serie.
  • Varias U seguidas: el resultado es 1 solo si todas se cumplen.
      U     E 0.0
      U     E 0.1           // y además E0.1
      =     A 4.0           // A4.0 = E0.0 ∧ E0.1

UN: Y negada (AND NOT)

UN significa «y además este bit vale 0». Es una Y con el operando invertido: RLO := RLO ∧ ¬operando.

  • En KOP equivale a un contacto NC en serie.
  • Es la forma de escribir condiciones como «marcha y no hay alarma»:
      U     E 0.0           // marcha
      UN    E 0.1           // y no hay alarma
      =     A 4.0           // A4.0 = E0.0 ∧ ¬E0.1

O: O (OR)

O significa «o este bit vale 1». Combina el RLO con el operando mediante una O: el resultado es 1 si se cumple alguna de las condiciones.

  • En KOP equivale a un contacto NA en paralelo.
  • Para un paralelo de contactos sueltos se escribe O también en la primera línea (O E 0.0 / O E 0.1), aunque U E 0.0 / O E 0.1 daría lo mismo: la primera instrucción solo copia el operando.
      O     E 0.0
      O     E 0.1           // o E0.1
      =     A 4.0           // A4.0 = E0.0 ∨ E0.1

ON: O negada (OR NOT)

ON significa «o este bit vale 0»: RLO := RLO ∨ ¬operando. En KOP equivale a un contacto NC en paralelo.

      O     E 0.0
      ON    E 0.1           // o E0.1 vale 0
      =     A 4.0           // A4.0 = E0.0 ∨ ¬E0.1

X y XN: O-exclusiva

X es la O-exclusiva: el resultado es 1 si solo uno de los dos vale 1, y 0 si valen lo mismo. XN es lo contrario: 1 cuando los dos valen lo mismo.

E 0.0E 0.1X E 0.0 / X E 0.1X E 0.0 / XN E 0.1
0001
0110
1010
1101

Un uso típico es la luz conmutada de un pasillo: dos interruptores, uno en cada extremo, y cualquiera de los dos cambia el estado de la luz. En KOP no hay contacto de O-exclusiva: se dibuja con dos ramas (ver Funciones lógicas con contactos), como en este esquema.

      X     E 0.0           // interruptor de un extremo del pasillo
      X     E 0.1           // interruptor del otro extremo
      =     A 4.0           // la luz cambia con cualquiera de los dos

=, S y R: escribir el resultado

Cuando la lógica está calculada, hay que escribir el RLO en algún sitio:

InstrucciónQué haceEn KOP
= A 4.0A 4.0 := RLO, siempre (1 o 0)Bobina
S A 4.0Si RLO = 1, A 4.0 := 1. Si RLO = 0, no hace nadaBobina
R A 4.0Si RLO = 1, A 4.0 := 0. Si RLO = 0, no hace nadaBobina
  • Después de =, S o R, la cadena se cierra: la siguiente U u O empieza una lógica nueva.
  • Se pueden escribir varias = seguidas para asignar el mismo resultado a varias salidas.
  • Con S y R el bit «recuerda» su valor. Pruébalo: un impulso en E 0.0 enciende A 4.0, que sigue encendida al soltar E 0.0, hasta que E 0.1 la apaga.
      U     E 0.0
      S     A 4.0           // si E0.0 = 1, A4.0 se pone a 1 y se queda
      U     E 0.1
      R     A 4.0           // si E0.1 = 1, A4.0 vuelve a 0

NOT, SET y CLR

Estas tres instrucciones no tienen operando y actúan directamente sobre el RLO:

InstrucciónQué haceEjemplo de uso
NOTInvierte el RLOU E 0.0 / U E 0.1 / NOT / = A 4.0 es una NAND
SETPone el RLO a 1Escribir un 1 fijo: SET / = M 0.0
CLRPone el RLO a 0Escribir un 0 fijo: CLR / = M 0.0

Cuidado con SET: no pone a 1 ningún operando, solo el RLO. Para activar un bit se usa S.

Formato

  • Una instrucción por línea. El código se divide en segmentos, igual que en KOP.
  • Metas (etiquetas): hasta 4 caracteres, empiezan por letra y terminan en :.
  • Comentarios con //. En las fuentes AWL cada instrucción termina en ;.
  • Los espacios entre área y dirección no importan: E 0.0 es lo mismo que E0.0.

Lógica de bits: RLO, primera consulta y STA

Cada instrucción lógica combina el RLO actual con el bit del operando:

InstrucciónSi /ER = 0 (primera consulta)Si /ER = 1 (cadena en curso)
U op (Y)RLO := opRLO := RLO ∧ op
UN op (Y-No)RLO := ¬opRLO := RLO ∧ ¬op
O op (O)RLO := opRLO := RLO ∨ op
ON op (O-No)RLO := ¬opRLO := RLO ∨ ¬op
X op (O-exclusiva)RLO := opRLO := RLO ⊕ op
XN op (O-exclusiva-No)RLO := ¬opRLO := RLO ⊕ ¬op

Después de cualquiera de ellas: /ER := 1 y STA := valor del operando.

Instrucciones que cierran la cadena (/ER := 0) sin cambiar el RLO:

  • =, S y R.
  • Las de temporizadores (SI, SV, SE, SS, SA, R T, FR T).
  • Las de contadores (ZV, ZR, S Z, R Z).

Por eso se pueden encadenar varias asignaciones con el mismo RLO:

      U     E 0.0
      U     E 0.1
      =     A 4.0      // A4.0 := E0.0 ∧ E0.1
      =     A 4.1      // A4.1 recibe el mismo RLO
      S     M 0.0      // y también activa M0.0 si es 1

Instrucciones que NO tocan el RLO ni /ER: L, T, la aritmética, la conversión, TAK, INC, DEC... Una cadena lógica puede continuar "por encima" de ellas:

      U     E 0.0
      L     MW 10      // no afecta al RLO
      T     MW 12      // se ejecuta SIEMPRE (T no depende del RLO)
      =     A 4.0      // A4.0 := E0.0

Operaciones directas sobre el RLO:

InstrucciónEfecto
NOTRLO := ¬RLO
SETRLO := 1 (y /ER := 0)
CLRRLO := 0 (y /ER := 0)
SAVERB := RLO

"Y antes de O": O sin operando y paréntesis

AWL evalúa de forma secuencial: U E0.0 / O E0.1 / U E0.2 calcula (E0.0 ∨ E0.1) ∧ E0.2, no E0.0 ∨ (E0.1 ∧ E0.2). Para agrupar hay dos herramientas.

a) O sin operando separa grupos Y que se combinan con O:

      U     E 0.0
      U     E 0.1
      O                 // (E0.0 ∧ E0.1)  ∨ ...
      U     E 0.2
      U     E 0.3
      =     A 4.0       // A4.0 = (E0.0 ∧ E0.1) ∨ (E0.2 ∧ E0.3)

Funcionamiento interno: O guarda el resultado del primer grupo en el bit OR y pone /ER = 0. Mientras OR = 1, las siguientes U y UN dejan el RLO a 1, porque el resultado ya está decidido. = pone OR := 0.

b) Paréntesis: U(, UN(, O(, ON(, X(, XN( ... ).

      U     E 0.0
      U(                // E0.0 ∧ ( ... )
      O     E 0.1
      O     E 0.2
      )
      =     A 4.1       // A4.1 = E0.0 ∧ (E0.1 ∨ E0.2)
  • Al abrir el paréntesis se guardan en la pila de anidamiento el RLO, el bit OR y la operación pendiente, y se empieza una cadena nueva (/ER = 0).
  • Al cerrar con ) se recupera lo guardado y se combina con el RLO del interior.
  • Se admiten hasta 7 niveles de anidamiento.

Bits de estado como operandos

U OV, U OS, U BIE (RB), U ==0, U <>0, U >0, U <0, U >=0, U <=0 y U UO (no ordenable). También funcionan con UN, O, ON, X y XN.

      L     MW 40
      L     MW 42
      +I
      T     MW 44
      U     OV              // ¿desbordó esta suma?
      =     M 1.0

Método de traza (para resolver ejercicios a mano)

Se anota, línea a línea, el estado de /ER, RLO, STA y OR. Ejemplo con E0.0 = 1, E0.1 = 0, E0.2 = 1 y E0.3 = 1:

Instrucción/ER antesSTARLO despuésORComentario
U E 0.00110Primera consulta: RLO := 1
U E 0.110001 ∧ 0
O1100OR := RLO (0); /ER := 0
U E 0.20110Primera consulta del 2.º grupo
U E 0.311101 ∧ 1
= A 4.01110A4.0 = 1; /ER := 0 (STA = valor escrito)

Con E0.0 = E0.1 = 1 y E0.2 = E0.3 = 0: tras O, el bit OR = 1. Las dos U siguientes dejan el RLO a 1, así que A4.0 = 1.

Conceptos: el bit OR y la primera consulta (ver "Y antes de O": O sin operando y paréntesis).

      U     E 0.1
      O

      U     E 0.3
      =     A 4.0

Enunciado: A4.1 = E0.0 ∧ (E0.1 ∨ E0.2).

      =     A 4.1

Ponte a prueba

Piensa la respuesta antes de abrir la solución.

Q01AWL se evalúa de forma secuencial

Con E0.0 = 1, E0.1 = 0 y E0.2 = 0, ¿cuánto vale A4.0?

      U     E 0.0
      O     E 0.1
      U     E 0.2
      =     A 4.0
Solución

A4.0 = 0. Se calcula (E0.0 ∨ E0.1) ∧ E0.2 = (1 ∨ 0) ∧ 0 = 0, no 1 ∨ (0 ∧ 0).

Q02O sin operando

Mismas entradas que en Q01. ¿Cuánto vale A4.0?

      U     E 0.0
      O
      U     E 0.1
      U     E 0.2
      =     A 4.0
Solución

A4.0 = 1. Se calcula E0.0 ∨ (E0.1 ∧ E0.2).

Preguntas frecuentes

¿Qué es el RLO en AWL?

El resultado lógico de la operación: el bit de la palabra de estado donde se va acumulando el resultado de las instrucciones lógicas (U, O, X…). Las asignaciones =, S y R lo escriben en un operando.

¿Para qué sirve el bit /ER (primera consulta)?

Indica si la siguiente instrucción lógica empieza una cadena nueva. Con /ER = 0, la siguiente U, O o X copia el operando en el RLO en lugar de combinarlo con él.

¿Por qué U a / O b / U c no calcula «a o (b y c)»?

Porque AWL evalúa de forma secuencial: calcula (a ∨ b) ∧ c. Para obtener a ∨ (b ∧ c) hay que usar O sin operando o paréntesis.

¿Cuántos paréntesis anidados admite AWL?

Siete niveles. Si se superan, hay un error y la CPU pasa a STOP.

¿Qué hace la instrucción SET en AWL?

Pone el RLO a 1 y cierra la cadena lógica (/ER = 0). No pone a 1 ningún operando: para eso está S.
