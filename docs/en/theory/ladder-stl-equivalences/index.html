Ladder ↔ STL equivalences: translating between the two languages

How to translate a Ladder network into STL and back: each element with its instruction, series and parallel patterns, and how boxes with EN/ENO are translated. With worked exercises.

Boxes with EN/ENO

When a box with EN is translated into STL, the editor generates a jump that skips it if EN = 0, and sets BR so that ENO shows whether there was an error. Simplified scheme of ADD_I with EN:

      A     I 0.0           // EN
      JNB   _001            // if EN = 0 → jump (and BR := 0)
      L     MW 10
      L     MW 12
      +I
      T     MW 14
      AN    OV              // no overflow…
      SAVE                  // …BR := 1
      CLR
_001: A     BR             // ENO = BR
      =     Q 4.0

Not all STL code can be converted to Ladder. For example: jumps inside a network, accumulator operations (TAK, standalone +I), indirect addressing or O without an operand in unusual positions. Those networks stay in STL.

Frequently asked questions

Can any STL program be converted to Ladder?

No. Jumps inside a network, standalone accumulator operations, indirect addressing or O without an operand in unusual positions have no Ladder drawing, and those networks stay in STL. The other way round, yes: all Ladder has its STL.

How are two contacts in parallel written in STL?

With O a / O b. If they are then in series with another contact, A c is added: O a / O b / A c calculates (a ∨ b) ∧ c.

How do you put a comparison in series with a contact in STL?

Inside brackets: A I 2.0 / A( / L MW 30 / L 500 / >I / ).
