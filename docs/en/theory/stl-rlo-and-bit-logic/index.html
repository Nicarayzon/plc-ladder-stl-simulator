Statement List (STL) step by step: A, AN, O, ON, X and the RLO

The STL (AWL) logic instructions explained one by one: A, AN, O, ON, X, XN, =, S, R and NOT, how the RLO is calculated, how to group with brackets and how to solve an exercise by hand, with examples you can try right here.

How to read an STL program

In STL the program is written as text, one instruction per line. Each line has an operation and, almost always, an operand:

LineOperationOperandRead as
A I 0.0A (AND)I 0.0"and input 0.0"
AN I 0.1AN (AND NOT)I 0.1"and not input 0.1"
= Q 4.0= (assign)Q 4.0"the result, to output 4.0"

These are the English (international) mnemonics. In the German mnemonics, A is written U, AN is UN, and the inputs and outputs are E and A (see German ↔ English mnemonics).

The CPU runs the lines from top to bottom. The logic instructions keep calculating a result, the RLO (result of logic operation), which is the same as the "power" in Ladder: each instruction combines the RLO with its operand, and at the end = writes it to an output.

Example, line by line, with I 0.0 = 1 and I 0.1 = 0:

InstructionWhat it doesRLO after
A I 0.0First instruction of the chain: copies I 0.01
A I 0.11 AND 00
= Q 4.0Writes the RLO to Q 4.0Q 4.0 = 0

The first logic instruction after an assignment does not combine anything: it copies its operand into the RLO. This is the "first check" (see Bit logic: RLO, first check and STA).

A: AND

A (German U) means "and also this bit is 1". It combines the RLO with the operand using an AND: the result only stays at 1 if the operand is 1.

  • In Ladder it is an NO contact in series.
  • Several A in a row: the result is 1 only if all of them are met.
      A     I 0.0
      A     I 0.1           // and also I0.1
      =     Q 4.0           // Q4.0 = I0.0 ∧ I0.1

AN: AND NOT

AN (German UN) means "and also this bit is 0". It is an AND with the operand inverted: RLO := RLO ∧ ¬operand.

  • In Ladder it is an NC contact in series.
  • It is how you write conditions such as "start and no alarm":
      A     I 0.0           // start
      AN    I 0.1           // and no alarm
      =     Q 4.0           // Q4.0 = I0.0 ∧ ¬I0.1

O: OR

O means "or this bit is 1". It combines the RLO with the operand using an OR: the result is 1 if any of the conditions is met.

  • In Ladder it is an NO contact in parallel.
  • For a parallel group of single contacts, O is also written on the first line (O I 0.0 / O I 0.1), although A I 0.0 / O I 0.1 would give the same result: the first instruction only copies the operand.
      O     I 0.0
      O     I 0.1           // or I0.1
      =     Q 4.0           // Q4.0 = I0.0 ∨ I0.1

ON: OR NOT

ON means "or this bit is 0": RLO := RLO ∨ ¬operand. In Ladder it is an NC contact in parallel.

      O     I 0.0
      ON    I 0.1           // or I0.1 is at 0
      =     Q 4.0           // Q4.0 = I0.0 ∨ ¬I0.1

X and XN: exclusive OR

X is the exclusive OR: the result is 1 if only one of the two is 1, and 0 if they are equal. XN is the opposite: 1 when both are equal.

I 0.0I 0.1X I 0.0 / X I 0.1X I 0.0 / XN I 0.1
0001
0110
1010
1101

A typical use is the two-way light switch of a corridor: two switches, one at each end, and either of them changes the state of the light. Ladder has no exclusive OR contact: it is drawn with two branches (see Logic functions with contacts), as in this diagram.

      X     I 0.0           // switch at one end of the corridor
      X     I 0.1           // switch at the other end
      =     Q 4.0           // either switch changes the light

=, S and R: writing the result

Once the logic has been calculated, the RLO has to be written somewhere:

InstructionWhat it doesIn Ladder
= Q 4.0Q 4.0 := RLO, always (1 or 0)Coil
S Q 4.0If RLO = 1, Q 4.0 := 1. If RLO = 0, it does nothingCoil
R Q 4.0If RLO = 1, Q 4.0 := 0. If RLO = 0, it does nothingCoil
  • After =, S or R, the chain is closed: the next A or O starts new logic.
  • You can write several = in a row to assign the same result to several outputs.
  • With S and R the bit "remembers" its value. Try it: a pulse on I 0.0 turns on Q 4.0, which stays on when I 0.0 is released, until I 0.1 turns it off.
      A     I 0.0
      S     Q 4.0           // if I0.0 = 1, Q4.0 is set to 1 and stays there
      A     I 0.1
      R     Q 4.0           // if I0.1 = 1, Q4.0 goes back to 0

NOT, SET and CLR

These three instructions have no operand and act directly on the RLO:

InstructionWhat it doesExample of use
NOTInverts the RLOA I 0.0 / A I 0.1 / NOT / = Q 4.0 is a NAND
SETSets the RLO to 1Writing a fixed 1: SET / = M 0.0
CLRSets the RLO to 0Writing a fixed 0: CLR / = M 0.0

Careful with SET: it does not set any operand to 1, only the RLO. To set a bit, use S.

Format

  • One instruction per line. The code is divided into networks, as in Ladder.
  • Labels: up to 4 characters, they start with a letter and end with :.
  • Comments start with //. In STL sources every instruction ends with ;.
  • Spaces between the area and the address do not matter: I 0.0 is the same as I0.0.

Bit logic: RLO, first check and STA

Each logic instruction combines the current RLO with the bit of the operand:

InstructionIf /FC = 0 (first check)If /FC = 1 (chain in progress)
A op (AND)RLO := opRLO := RLO ∧ op
AN op (AND NOT)RLO := ¬opRLO := RLO ∧ ¬op
O op (OR)RLO := opRLO := RLO ∨ op
ON op (OR NOT)RLO := ¬opRLO := RLO ∨ ¬op
X op (exclusive OR)RLO := opRLO := RLO ⊕ op
XN op (exclusive OR NOT)RLO := ¬opRLO := RLO ⊕ ¬op

After any of them: /FC := 1 and STA := value of the operand.

Instructions that close the chain (/FC := 0) without changing the RLO:

  • =, S and R.
  • Timer instructions (SP, SE, SD, SS, SF, R T, FR T).
  • Counter instructions (CU, CD, S C, R C).

That is why several assignments can be chained with the same RLO:

      A     I 0.0
      A     I 0.1
      =     Q 4.0      // Q4.0 := I0.0 ∧ I0.1
      =     Q 4.1      // Q4.1 gets the same RLO
      S     M 0.0      // and M0.0 is also set if it is 1

Instructions that do NOT affect the RLO or /FC: L, T, arithmetic, conversion, TAK, INC, DEC... A logic chain can carry on "over" them:

      A     I 0.0
      L     MW 10      // does not affect the RLO
      T     MW 12      // ALWAYS executed (T does not depend on the RLO)
      =     Q 4.0      // Q4.0 := I0.0

Direct operations on the RLO:

InstructionEffect
NOTRLO := ¬RLO
SETRLO := 1 (and /FC := 0)
CLRRLO := 0 (and /FC := 0)
SAVEBR := RLO

"AND before OR": O without operand and brackets

STL evaluates sequentially: A I0.0 / O I0.1 / A I0.2 calculates (I0.0 ∨ I0.1) ∧ I0.2, not I0.0 ∨ (I0.1 ∧ I0.2). There are two tools for grouping.

a) O without an operand separates AND groups that are combined with OR:

      A     I 0.0
      A     I 0.1
      O                 // (I0.0 ∧ I0.1)  ∨ ...
      A     I 0.2
      A     I 0.3
      =     Q 4.0       // Q4.0 = (I0.0 ∧ I0.1) ∨ (I0.2 ∧ I0.3)

How it works inside: O stores the result of the first group in the OR bit and sets /FC = 0. While OR = 1, the following A and AN leave the RLO at 1, because the result has already been decided. = sets OR := 0.

b) Brackets: A(, AN(, O(, ON(, X(, XN( ... ).

      A     I 0.0
      A(                // I0.0 ∧ ( ... )
      O     I 0.1
      O     I 0.2
      )
      =     Q 4.1       // Q4.1 = I0.0 ∧ (I0.1 ∨ I0.2)
  • When a bracket is opened, the RLO, the OR bit and the pending operation are saved on the nesting stack, and a new chain starts (/FC = 0).
  • When it is closed with ), the saved values are restored and combined with the RLO from inside the bracket.
  • Up to 7 levels of nesting are allowed.

Status bits as operands

A OV, A OS, A BR, A ==0, A <>0, A >0, A <0, A >=0, A <=0 and A UO (unordered). They also work with AN, O, ON, X and XN.

      L     MW 40
      L     MW 42
      +I
      T     MW 44
      A     OV              // did this addition overflow?
      =     M 1.0

Trace method (for solving exercises by hand)

Write down, line by line, the state of /FC, RLO, STA and OR. Example with I0.0 = 1, I0.1 = 0, I0.2 = 1 and I0.3 = 1:

Instruction/FC beforeSTARLO afterORComment
A I 0.00110First check: RLO := 1
A I 0.110001 ∧ 0
O1100OR := RLO (0); /FC := 0
A I 0.20110First check of the 2nd group
A I 0.311101 ∧ 1
= Q 4.01110Q4.0 = 1; /FC := 0 (STA = value written)

With I0.0 = I0.1 = 1 and I0.2 = I0.3 = 0: after O, the OR bit = 1. The two following A instructions leave the RLO at 1, so Q4.0 = 1.

Test yourself

Work out the answer before you open the solution.

Q01STL is evaluated sequentially

With I0.0 = 1, I0.1 = 0 and I0.2 = 0, what is the value of Q4.0?

      A     I 0.0
      O     I 0.1
      A     I 0.2
      =     Q 4.0
Solution

Q4.0 = 0. It calculates (I0.0 ∨ I0.1) ∧ I0.2 = (1 ∨ 0) ∧ 0 = 0, not 1 ∨ (0 ∧ 0).

Q02O without operand

Same inputs as in Q01. What is the value of Q4.0?

      A     I 0.0
      O
      A     I 0.1
      A     I 0.2
      =     Q 4.0
Solution

Q4.0 = 1. It calculates I0.0 ∨ (I0.1 ∧ I0.2).

Frequently asked questions

What is the RLO in STL?

The result of logic operation: the bit of the status word where the result of the logic instructions (A, O, X…) builds up. The assignments =, S and R write it to an operand.

What is the /FC (first check) bit for?

It shows whether the next logic instruction starts a new chain. With /FC = 0, the next A, O or X copies the operand into the RLO instead of combining it with it.

Why doesn't A a / O b / A c calculate "a or (b and c)"?

Because STL evaluates sequentially: it calculates (a ∨ b) ∧ c. To get a ∨ (b ∧ c) you need O without an operand or brackets.

How many nested brackets does STL allow?

Seven levels. If they are exceeded, there is an error and the CPU goes to STOP.

What does the SET instruction do in STL?

It sets the RLO to 1 and closes the logic chain (/FC = 0). It does not set any operand to 1: that is what S is for.
