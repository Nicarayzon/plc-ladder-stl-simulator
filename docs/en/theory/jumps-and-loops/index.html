Jumps and loops in STL: JU, JC, JCN and LOOP

Conditional and unconditional jumps in STL (JU, JC, JCN, JZ…), their Ladder equivalent (JMP, JMPN) and loops with LOOP, with the pitfalls that come up most often in exams.

Trap: if JC does not jump, the RLO is left at 1. A I0.0 / JC X / = Q4.0 sets Q4.0 = 1 when I0.0 = 0.

Trap with LOOP: if ACCU1-L is 0 when LOOP is reached, it becomes 65535 and the loop body runs another 65535 times. You have to check first that the counter is greater than 0.

Loop with LOOP:

      L     5
SIG:  T     MW 10           // loop counter
      // ... loop body (uses MW10) ...
      L     MW 10
      LOOP  SIG             // MW10−1; repeats while ≠ 0

Worked examples

E26Add or subtract depending on a selector (jumps)

Task: if I0.0 = 1, MW34 = MW30 + MW32. Otherwise, MW34 = MW30 − MW32.

      A     I 0.0
      JC    SUMA
      L     MW 30
      L     MW 32
      -I
      T     MW 34
      JU    FIN
SUMA: L     MW 30
      L     MW 32
      +I
      T     MW 34
FIN:  NOP   0

E27Factorial with LOOP

Task: MD100 = MW30! If MW30 ≤ 1, the result is 1.

Concepts: LOOP decrements ACCU1-L and jumps while it is ≠ 0. You have to protect the case 0: otherwise LOOP would go from 0 to 65535 and repeat the loop another 65535 times.

      L     L#1
      T     MD 100      // result = 1
      L     MW 30       // N
      L     1
      <=I               // N <= 1?
      JC    FIN
      L     MW 30
SIG:  T     MW 32       // loop counter
      L     MD 100
      L     MW 32
      *D
      T     MD 100
      L     MW 32
      LOOP  SIG
FIN:  NOP   0

Test yourself

Work out the answer before you open the solution.

Q08JC not taken

What is the value of Q4.0 at each step? The input keeps changing: first I0.0 = 1, then I0.0 = 0 and then I0.0 = 1.

      A     I 0.0
      JC    FIN
      =     Q 4.0
FIN:  NOP   0
Solution
  • With I0.0 = 1: it jumps and Q4.0 is not written, so it stays at 0.
  • With I0.0 = 0: it does not jump, but JC leaves RLO = 1, so Q4.0 = 1.
  • With I0.0 = 1 again: it jumps and Q4.0 stays at 1.

Frequently asked questions

What are the RLO and /FC when a JC does not jump?

RLO = 1 and /FC = 0. JC and JCN always leave the RLO at 1 and close the chain, whether they jump or not. That is why an assignment right after a JC that does not jump writes a 1.

How do you make a loop in STL?

With LOOP: it subtracts 1 from the low part of ACCU1 and jumps to the label as long as it does not reach 0. Check first that the counter is not 0, because it would become 65535 and the loop would repeat 65535 times.

How do I make a transfer happen only when a condition is met?

By jumping over it: A I0.0 / JCN NO / L 5 / T MW10 / NO: NOP 0. T does not depend on the RLO, so putting the condition in front of it is not enough.
