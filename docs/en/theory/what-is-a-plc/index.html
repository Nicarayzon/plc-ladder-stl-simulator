What is a PLC: parts, languages and where to start

Introduction to programmable logic controllers: what a PLC is, its parts, how it differs from relays and from an Arduino, which programming languages exist (Ladder, FBD, STL, structured text and GRAFCET) and which one to learn first.

What is a PLC?

A PLC (programmable logic controller) is a computer designed to control industrial machines and installations. It does the same thing over and over, without stopping:

  1. It reads the inputs: push buttons, switches, limit switches, presence sensors, level or temperature probes.
  2. It runs the program: it decides what to do depending on the state of the inputs, the time that has passed and what it remembers (bit memory, timers and counters).
  3. It writes the outputs: it starts motors through contactors, opens valves, turns on lamps or moves cylinders.

This repetition is called the scan cycle, and it usually takes a few milliseconds (see The scan cycle).

Before PLCs, the logic of a machine was built by wiring relays: to change how it worked, the control cabinet had to be rewired. With a PLC, the wiring of the inputs and outputs stays the same and what changes is the program.

Parts of a PLC

PartWhat it is for
Power supplyConverts the mains voltage into the 24 V DC used by the CPU and the modules
CPURuns the program and stores the data: process image, bit memory, timers, counters and data blocks (see Memory areas: Overview)
Digital inputsRead on/off signals (0 or 1), usually at 24 V
Digital outputsDrive contactors, solenoid valves or lamps, through a transistor or a relay
Analog inputs and outputsRead or generate continuous values, such as 0..10 V or 4..20 mA, which the CPU sees as numbers from 0 to 27648 (see Memory areas: I/O addresses)
CommunicationConnects to the programming computer, to touch panels (HMI) and to other PLCs

In compact PLCs everything comes in one box: the CPU with its onboard inputs and outputs. In modular PLCs, each part is a module mounted on a rack next to the CPU, and you add the ones you need.

A microcontroller is good for learning electronics and for prototypes. An industrial machine uses a PLC because it is built for that environment, any maintenance technician understands it, and it can be replaced and repaired for many years.

PLC programming languages

The IEC 61131-3 standard defines the programming languages of PLCs. The German names (KOP, FUP, AWL) are also very common in training:

LanguageAlso calledWhat it looks likeWhat it is good for
LadderLAD, LD (KOP in German)Graphical, like an electrical diagram of contacts and coilsBit logic, latching and timers. Electricians understand it straight away
Function block diagramFBD (FUP in German)Graphical, with AND, OR and flip-flop boxes… as in digital electronicsThe same logic as Ladder, drawn with logic gates
Statement ListSTL, IL (AWL in German)Text, one instruction per line, very close to how the CPU worksUnderstanding the CPU from the inside, existing programs, exams
Structured textSTText similar to Pascal, with IF, FOR and formulasCalculations, loops and data handling
GRAFCETSequential function chart (SFC)Graphical, with steps and transitionsStep sequences (see What a sequence is)

The same program can be written in Ladder or in STL: the editor translates each Ladder network into STL (see Ladder ↔ STL: Elements). Not all STL has a Ladder drawing, but all Ladder has its STL.

Which language should you learn?

  • Start with Ladder. It reads like an electrical diagram and teaches the essentials: contacts, coils, latching, edges, timers and counters.
  • Learn STL to understand the CPU. With STL you see the RLO, the accumulators and the order in which each instruction runs, and you understand why a program does what it does. The 2013 edition of IEC 61131-3 marked it as deprecated and it is used less and less in new equipment, but it is still in a huge number of machines in operation and in vocational and engineering exams.
  • Then structured text (ST), for calculations and data handling, and GRAFCET for sequences.

Worked examples

Your first program: a switch turns on a lamp

Task: the lamp Q4.0 is on while the switch I0.0 is at 1. It is the simplest possible program: a normally open contact and a coil. Switch on I0.0 and watch how the power flows through the diagram, from left to right.

      A     I 0.0           // if the switch is at 1…
      =     Q 4.0           // …the lamp turns on

Frequently asked questions

What is a PLC (programmable logic controller)?

It is an industrial computer that controls machines and installations: it reads push buttons and sensors through its inputs, runs a program in a cycle that repeats without stopping, and drives motors, valves or lamps through its outputs. It replaces control circuits wired with relays.

What is the difference between a PLC and an Arduino?

A PLC is built for industry: 24 V inputs and outputs, resistance to electrical noise and vibration, predictable cyclic execution, standardized languages (IEC 61131-3) and spare parts for many years. An Arduino is a microcontroller board designed for learning and prototyping, and it is programmed in C++.

Which PLC language should I learn first?

Ladder (LAD), because it reads like an electrical diagram. Then STL, to understand how the CPU works inside, and later structured text (ST) for calculations and GRAFCET for sequences.

Do I need a real PLC to learn to program one?

No. With a simulator you can write programs in Ladder and STL, operate the inputs and see how the outputs, timers and counters respond. When you work with a real PLC, you will arrive with the program already tested.
