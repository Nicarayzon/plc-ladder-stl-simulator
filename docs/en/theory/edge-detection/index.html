Rising and falling edges in Ladder and STL (P, N, FP and FN)

What a rising or falling edge is, how it is detected in Ladder with (P) and (N) and in STL with FP and FN, why each edge needs its own memory bit, and how to build a toggle (impulse) relay.

Edges in Ladder

has an edge memory bit on top, where it stores the RLO of the previous cycle. Its output is 1 only in the cycle in which the RLO changes from 0 to 1.

Timing diagram:

Typical uses: counting button presses, the toggle relay (a single push button that switches on and off) and running an action only once.

Edges in STL

InstructionPseudocode
FP mprev := m; m := RLO; RLO := RLO ∧ ¬prev
FN mprev := m; m := RLO; RLO := ¬RLO ∧ prev
      A     I 0.0
      FP    M 10.0          // M10.0 = edge memory bit (exclusive)
      =     M 10.1          // M10.1 = 1 only in the cycle of the edge

Worked examples

E10Rising and falling edge

Task: M10.1 = one-cycle pulse when I0.0 is pressed. M10.3 = one-cycle pulse when it is released.

Concepts: each edge needs its own edge memory bit (M10.0 and M10.2).

      A     I 0.0
      FP    M 10.0
      =     M 10.1
      A     I 0.0
      FN    M 10.2
      =     M 10.3

E11Toggle relay (one push button switches on and off)

Task: each press of I0.0 changes the state of lamp Q4.0.

Concepts: edge + self-holding with two branches.

      A     I 0.0
      FP    M 10.0
      =     M 10.1      // pulse
      A     M 10.1
      AN    Q 4.0
      O
      AN    M 10.1
      A     Q 4.0
      =     Q 4.0

Frequently asked questions

What is a rising edge in a PLC?

The change of a signal from 0 to 1. An edge detector gives 1 only during the cycle in which that change happens, even if the signal stays at 1 afterwards. The falling edge is the change from 1 to 0.

Why does each edge need its own memory bit?

Because the edge memory bit stores the state of the previous cycle. If two FP share the same bit, each one overwrites what the other has stored and both fail.

How do I make one push button switch a lamp on and off?

With a toggle relay: a rising edge of the push button and a latching circuit that changes the state of the output on each edge (example E11). Without the edge, the output would change on every cycle while the button is held down.
