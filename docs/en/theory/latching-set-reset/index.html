Start and stop: latching, Set and Reset in Ladder and STL

How to program a start/stop circuit in Ladder and STL: latching (self-holding), Set and Reset coils, SR and RS flip-flops, and how the priority between start and stop is decided.

In Ladder: coils, latching and flip-flops

Latching (self-holding): start and stop with stop priority.

Set/Reset with coils: the one that is executed last has priority.

SR / RS box:

One coil per operand. If the same bit has two coils, only the last one counts. S and R coils for the same bit can appear several times: that is normal.

In STL: assignment, Set and Reset

InstructionEffectPriority
= opop := RLO, always—
S opif RLO = 1 → op := 1 (if RLO = 0 it does nothing)—
R opif RLO = 1 → op := 0—

When the same bit has S and R, the one that is executed last wins:

      A     I 0.0           // start
      S     Q 4.0
      A     I 0.1           // stop
      R     Q 4.0           // R at the end → reset (stop) priority

Worked examples

E06Start and stop with latching (stop priority)

Task: I0.0 = start (NO push button). I0.1 = stop (wired NC push button, so it is 1 at rest). Q4.0 = motor.

Concepts: self-holding, safety through wiring and stop priority.

      A(
      O     I 0.0       // start
      O     Q 4.0       // feedback (latching)
      )
      A     I 0.1       // NC stop: 1 = not pressed
      =     Q 4.0

E07Start and stop with Set/Reset (stop priority)

Concepts: the priority is given by the order: the last instruction wins.

      A     I 0.0
      S     Q 4.0
      AN    I 0.1       // stop pressed (I0.1 = 0)
      R     Q 4.0       // R at the end → stop priority

E08Start and stop with start priority

Task: the same as E07, but if both are pressed, start must win.

      AN    I 0.1
      R     Q 4.0
      A     I 0.0
      S     Q 4.0

Frequently asked questions

What is latching (self-holding)?

A circuit in which the output stays on through its own contact: the start button switches it on and, when it is released, the contact of the output itself keeps it on until the stop button is pressed.

If a bit has Set and Reset active at the same time, which one wins?

The instruction that is executed last. With the Reset after it, stop wins; with the Set after it, start wins. The priority comes from the order, not from the type of coil.

Which STL instruction is equivalent to the (S) coil in Ladder?

S. Do not confuse it with SET, which sets the RLO to 1, or with SE, which starts a timer (an extended pulse, in English mnemonics).

What is the difference between the SR and RS flip-flops?

With both inputs at 1, SR gives priority to reset (Q = 0) and RS to set (Q = 1).
