How a PLC works: the scan cycle

How a programmable logic controller runs its program: it reads the inputs, executes OB1 and writes the outputs. What this means for your Ladder and STL programs, and why a normally closed stop button is programmed with a normally open contact.

The scan cycle

The CPU runs the program cyclically. In each cycle:

  1. It reads the inputs. It copies the state of the physical inputs into the process image of inputs (PII).
  2. It executes the program. It runs OB1 and all the blocks it calls (FC, FB...), instruction by instruction and from top to bottom.
  3. It writes the outputs. It copies the process image of outputs (PIQ) to the physical outputs.
  4. Internal tasks. It handles communication (programming device, HMI) and self-diagnostics, and goes back to step 1.

The cycle time is monitored. The default limit is 150 ms and it is set in the CPU properties. If it is exceeded, OB80 is called, and if OB80 does not exist the CPU goes to STOP. An endless loop (for example, a backward jump that never ends) causes exactly that.

Timers run asynchronously to the program: they are updated by the operating system, not by the cycle.

Practical consequences (often asked)

FactConsequence
The PII is read once at the start of the cycleAn input has the same value for the whole cycle, even if it changes physically halfway through
The PIQ is written at the endIf the same output is assigned twice, only the last assignment counts (double assignment)
The program runs in orderWhat one network calculates is seen by the following networks in the same cycle. The previous ones do not see it until the next cycle
Outputs can be readA Q 4.0 reads the PIQ, that is, the last value written by the program. This is how latching works
Direct peripheral access (PIW, PQW)It bypasses the process image: it reads or writes the module at that very moment

Safety wiring: physical contact ≠ program contact

  • A program contact only checks the state of a bit: whether it is 1 or 0. It does not know how the push button is wired.
  • Stop buttons, emergency stops and safety limit switches are wired normally closed (NC). At rest the input is 1. If the wire breaks, the input drops to 0 and the machine stops (fail-safe).
  • That is why an NC stop button is programmed with an NO contact (A I 0.1): the motor can run while the input is 1.

CPU modes and startup

  • Modes: RUN, RUN-P (RUN with programming), STOP and MRES (memory reset). They are selected with the CPU mode selector.
  • Status LEDs:
    • SF: system fault.
    • BF: bus fault.
    • DC5V: power supply.
    • FRCE: force active.
    • RUN and STOP: current mode.
  • Startup (complete restart / warm restart): OB100 runs once and then the OB1 cycle starts. In this startup:
    • Non-retentive bit memory, timers and counters are reset to 0.
    • The PIQ is reset to 0.
    • Retentive data keep their value.

Worked examples

E09Double assignment (typical mistake)

Task: Q4.0 should turn on with I0.0 or with I0.1. This program is wrong.

Concepts: the PIQ is written at the end of the cycle, so only the last assignment counts.

      A     I 0.0
      =     Q 4.0
      A     I 0.1
      =     Q 4.0       // overwrites the previous one

E09bDouble assignment, corrected

      O     I 0.0
      O     I 0.1
      =     Q 4.0

Test yourself

Work out the answer before you open the solution.

Q12Order of the networks

I0.0 is set to 1. What is the value of Q4.0 at the end of the first cycle? And at the end of the second?

      A     M 0.0
      =     Q 4.0
      A     I 0.0
      =     M 0.0
Solution
  • Cycle 1: Q4.0 = 0. M0.0 is calculated after it is used.
  • Cycle 2: Q4.0 = 1.

Frequently asked questions

What is the scan cycle of a PLC?

It is the loop that the CPU repeats without stopping: it reads the inputs into the process image (PII), runs OB1 from top to bottom and copies the output image (PIQ) to the physical outputs. Then it handles communication and starts again.

If I assign the same output in two places, which value reaches the output?

The value of the last assignment executed. The PIQ is written at the end of the cycle, so the last assignment overwrites the previous ones. To combine conditions, use an OR or Set and Reset coils.

Why is the stop button programmed with a normally open contact?

Because the stop button is wired as an NC contact: at rest the input is 1, and the NO contact in the program only asks "is it 1?". If the wire breaks, the input drops to 0 and the machine stops, which is the safe result.

Which OB runs only once when the CPU starts?

OB100, in the complete restart when the CPU goes from STOP to RUN. It is used for initialization. After it, the OB1 cycle begins.
