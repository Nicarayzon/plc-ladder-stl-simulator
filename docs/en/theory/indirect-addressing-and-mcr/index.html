Indirect addressing and MCR in STL

Memory-indirect and register-indirect addressing in STL, the area pointer format and the Master Control Relay (MCR), with an example that adds up a table of words.

Indirect addressing (advanced)

  • Memory-indirect: the address is in a memory word or a data item, in pointer format. For example: L MW [MD 30] or A I [MD 34].
  • Register-indirect: LAR1 P#M 100.0 and then L MW [AR1, P#2.0].
  • Area pointer format (32 bits): byte number × 8 + bit number. For example, P#10.0 is equivalent to 80.

Example: adding up MW100..MW118 by stepping through them with a pointer.

      L     P#100.0
      T     MD 30           // pointer to the first element
      L     0
      T     MW 40           // sum = 0
      L     10              // 10 elements
SIG:  T     MW 34
      L     MW 40
      L     MW [MD 30]
      +I
      T     MW 40
      L     MD 30
      L     P#2.0           // next word
      +D
      T     MD 30
      L     MW 34
      LOOP  SIG

MCR (Master Control Relay)

  • MCRA activates the MCR area and MCRD deactivates it.
  • Inside MCR( … )MCR, if the condition before MCR( is 0, all = assignments and T transfers write 0. S and R have no effect.
  • It does not replace a hard-wired emergency stop circuit.

Worked examples

E29Adding up a table with indirect addressing

Task: MW40 = sum of the 10 words MW100, MW102, …, MW118.

Concepts: area pointer (P#byte.bit = byte × 8 + bit), L MW [MD 30] and LOOP (see Indirect addressing (advanced)). It only exists in STL: it has no Ladder representation.

      L     P#100.0
      T     MD 30       // pointer to the first element (100 × 8 = 800)
      L     0
      T     MW 40       // sum = 0
      L     10          // 10 elements
SIG:  T     MW 34       // loop counter
      L     MW 40
      L     MW [MD 30]
      +I
      T     MW 40
      L     MD 30
      L     P#2.0       // moves on one word (2 bytes = 16)
      +D
      T     MD 30
      L     MW 34
      LOOP  SIG

Frequently asked questions

What is indirect addressing in STL?

Using an address that is stored somewhere else, instead of writing it fixed in the code. For example, L MW [MD 30] loads the word whose address is held in MD30. It is used to step through tables in a loop.

How is a P# pointer calculated?

Byte number × 8 + bit number. P#10.0 is 80 and P#2.0 is 16: that is why adding P#2.0 to a pointer moves it on by one word.

Does the MCR replace an emergency stop?

No. The MCR only makes the = assignments and the T transfers of one area of the program write 0. An emergency stop has to be wired separately, outside the program.
