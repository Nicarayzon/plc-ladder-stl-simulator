Ladder logic (LAD) step by step: contacts, coils, series and parallel

How to read and program a Ladder diagram (LAD, called KOP in German), step by step: normally open and normally closed contacts, contacts in series (AND) and in parallel (OR), coils, Set, Reset and NOT, with examples you can try right here and their STL equivalent.

How to read a Ladder diagram

A Ladder program is drawn like an electrical diagram of contacts and coils, and it is read the same way:

  • The program is divided into networks. Each network is one "line" of the diagram, with its logic and its output.
  • On the left is the power rail: the "power" comes from it.
  • The power flows from left to right through the contacts. Each contact lets the power through or cuts it, depending on the value of a bit (an input, an output, a memory bit…).
  • On the right is the coil: if power reaches it, it writes a 1 to its bit; if not, it writes a 0.

That "power" is not real electricity: it is the logic result that the CPU calculates when it runs the network, a 1 or a 0. In STL it is called the RLO (see Bit logic: RLO, first check and STA). In the simulator, the part that carries power is shown in solid green and the part that does not, in dashed blue.

Try it: switch on input I 0.0 and watch the power go through the contact and reach the coil, which turns on output Q 4.0.

      A     I 0.0           // is I0.0 at 1?
      =     Q 4.0           // the result, to the output

Normally open (NO) contact

The NO contact asks: "is this bit 1?"

Bit of the contactDoes it conduct?
0No: it cuts the power
1Yes: it lets the power through

It works like a normally open push button: when the bit is 1, it "closes" the circuit. It is the most widely used contact: it reads push buttons, sensors, memory bits and also outputs. In STL it is the A instruction (see STL: RLO and bit logic: A: AND).

Normally closed (NC) contact

The NC contact asks: "is this bit 0?". It is the NO contact the other way round:

Bit of the contactDoes it conduct?
0Yes: it lets the power through
1No: it cuts the power

Try it: with I 0.0 at 0 the lamp is on. When you switch on I 0.0, the contact opens and the lamp goes off.

      AN    I 0.0           // is I0.0 at 0?
      =     Q 4.0

In STL it is AN (see AN: AND NOT).

Do not confuse the program contact with the real push button. The program contact only asks for the value of the bit; it does not know how the push button is wired. A stop button is wired NC (it gives 1 at rest) and in the program it is checked with an NO contact (see Safety wiring: physical contact ≠ program contact).

Contacts in series: the AND function

When you place contacts one after another, power only reaches the coil if all of them conduct. This is the AND function:

I 0.0I 0.1Q 4.0
000
010
100
111

Try it: Q 4.0 only turns on with both inputs switched on.

      A     I 0.0
      A     I 0.1           // and also I0.1
      =     Q 4.0           // Q4.0 = I0.0 ∧ I0.1

You can mix NO and NC contacts in series. For example, "start and no alarm" is an NO contact for start in series with an NC contact for the alarm:

      A     I 0.0           // start
      AN    I 0.1           // and no alarm
      =     Q 4.0           // Q4.0 = I0.0 ∧ ¬I0.1

Contacts in parallel: the OR function

When you place contacts in parallel branches, power reaches the coil if at least one branch conducts. This is the OR function:

I 0.0I 0.1Q 4.0
000
011
101
111

It is used, for example, to switch on a light from two different push buttons. Try it:

      O     I 0.0
      O     I 0.1           // or I0.1
      =     Q 4.0           // Q4.0 = I0.0 ∨ I0.1

A parallel branch can also have an NC contact: here Q 4.0 turns on if I 0.0 is 1 or if I 0.1 is 0.

      O     I 0.0
      ON    I 0.1           // or I0.1 is at 0
      =     Q 4.0           // Q4.0 = I0.0 ∨ ¬I0.1

Combining series and parallel

Real diagrams mix both, and they are read just like an electrical circuit: the power has to go through one of the parallel branches and then through the contacts in series.

In this example, Q 4.0 = (I 0.0 or I 0.1) and I 0.2. Try it: switch on I 0.2 and then one of the other two.

      A(
      O     I 0.0
      O     I 0.1
      )
      A     I 0.2
      =     Q 4.0           // Q4.0 = (I0.0 ∨ I0.1) ∧ I0.2

Almost every control circuit is built like this. For example, a start/stop circuit with latching is "(start or the motor itself) and stop" (see In Ladder: coils, latching and flip-flops). To turn a combination like this into STL you use brackets or O without an operand (see "AND before OR": O without operand and brackets and Series and parallel patterns).

Coils, Set, Reset and NOT

The elements on the right of the network write the result:

  • Coil : it always writes the result: 1 if power reaches it, 0 if not. Each operand should have only one coil in the whole program; if it has two, only the last one counts (see Practical consequences (often asked)).
  • Several coils in parallel at the end of a network receive the same power: they all have the same value.
  • Set and Reset : if power reaches them, they set the bit to 1 or to 0; if not, they do nothing and the bit keeps its value. They are used to "remember" (see In Ladder: coils, latching and flip-flops).
  • NOT : it inverts the power. What comes in as 1 goes out as 0, and the other way round.

Try it: with I 0.0, the two coils of the first network turn on together; the one in the second network does the opposite, because of the NOT.

      A     I 0.0
      =     Q 4.0           // two assignments with the same RLO
      =     Q 4.1
      A     I 0.0
      NOT                   // inverts the RLO
      =     Q 4.2

Summary and construction rules

  • Network: the program unit. Each network has a title, a comment and its circuit.
  • Power rail: on the left. "Power" flows from left to right.
  • Contact: checks the state of a bit.
    • NO conducts if the bit is 1.
    • NC conducts if the bit is 0.
  • Series = AND. Parallel = OR.
  • Coil: writes the result of the logic on its left (the RLO) to a bit.
  • Box: a function with an enable input EN and an output ENO. ENO = 1 if EN = 1 and the operation finished without errors.

Construction rules:

  • Output elements (coils and final boxes) go on the right. Several coils in parallel can be placed at the end of a network.
  • The connector and some boxes can go in the middle of a branch.
  • Power cannot flow from right to left, and branches cannot be left open.
  • A jump label (LABEL) always goes at the start of a network.
  • If a network written in STL has no graphical representation, it stays in STL when the view is switched.

Online monitoring: power flow is shown in solid green and the absence of flow in dashed blue.

Status bits as contacts

Contacts OV, OS, UO, BR, ==0, <>0, >0, <0, >=0 and <=0. They check the result of the last arithmetic or comparison operation (see STL: RLO and bit logic: CPU registers).

Worked examples

E01NO contact and NC contact

Task: lamp Q4.0 turns on when I0.0 = 1, and lamp Q4.1 when I0.0 = 0.

Concepts: a contact checks the state of a bit (see Safety wiring: physical contact ≠ program contact and Bit logic operations).

      A     I 0.0
      =     Q 4.0
      AN    I 0.0
      =     Q 4.1

E02AND (series) and OR (parallel)

Task: Q4.0 = I0.0 AND I0.1. Q4.1 = I0.0 OR I0.1.

// Network 1: AND
      A     I 0.0
      A     I 0.1
      =     Q 4.0
// Network 2: OR
      O     I 0.0
      O     I 0.1
      =     Q 4.1

E03NAND, NOR and exclusive OR

Task: Q4.0 = NAND, Q4.1 = NOR and Q4.2 = XOR of I0.0 and I0.1.

// NAND
      A     I 0.0
      A     I 0.1
      NOT
      =     Q 4.0
// NOR
      O     I 0.0
      O     I 0.1
      NOT
      =     Q 4.1
// XOR (STL has the X instruction)
      X     I 0.0
      X     I 0.1
      =     Q 4.2

Frequently asked questions

What is Ladder logic?

It is the graphical PLC language that looks like an electrical diagram: power comes out of a rail on the left, goes through contacts and reaches coils on the right. It is also called LAD or LD, and KOP in German.

What is the difference between an NO and an NC contact in Ladder?

The NO contact conducts when its bit is 1, and the NC contact when it is 0. Both only ask for the state of the bit: they do not know how the real push button is wired.

What do two contacts in series or in parallel mean?

In series, an AND function: power only gets through if both conduct. In parallel, an OR function: it is enough for one of them to conduct.
