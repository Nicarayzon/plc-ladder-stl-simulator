Solved PLC exercises: tank, staircase timer, counter and star-delta

Typical PLC exercises solved in Ladder and STL and checked in the simulator: filling a tank with hysteresis, a staircase light timer, a warning every 5 parts and a star-delta motor start.

How to use these exercises

These are typical class and exam exercises, solved and checked with automatic tests in the simulator. For each one:

  1. Read the task and try to solve it before looking at anything. If you get stuck, open the hint under «Solution».
  2. Compare your program with the solution in Ladder and in STL.
  3. Try it in the panel: operate the inputs and check that the outputs do what the task asks.

The exercises use push buttons and sensors with absolute addresses. Stop buttons are wired NC, so they start at 1 (see Safety wiring: physical contact ≠ program contact).

Worked examples

P01Filling a tank with hysteresis

Task:

  • I0.2 = low-level probe (1 = the water is above the minimum).
  • I0.3 = high-level probe (1 = the water reaches the maximum).
  • I0.1 = stop (NC).

Pump Q4.0 starts when the level drops below the minimum and stops when it reaches the maximum. Between the two probes it keeps its state. The stop button stops it.

Solution

Set below the minimum; Reset at the maximum or with the stop button (the Resets come after: stop priority).

      AN    I 0.2
      S     Q 4.0
      A     I 0.3
      R     Q 4.0
      AN    I 0.1
      R     Q 4.0

P02Staircase light timer

Task: a pulse on I0.0 turns on light Q4.0 for 30 s. If it is pressed again while the light is on, the 30 s start again.

Solution

Extended pulse (SE in English mnemonics, SV in German): it retriggers on every edge.

      A     I 0.0
      L     S5T#30S
      SE    T 1
      A     T 1
      =     Q 4.0

P03Packing: a warning every 5 parts

Task: I1.0 = part sensor. When 5 parts have arrived, warning Q5.0 turns on for 2 s and the counter goes back to 0 automatically.

Solution

Up counter + comparison ≥ 5 that triggers a 2 s extended pulse and resets the counter.

      A     I 1.0
      CU    C 1
      L     C 1
      L     5
      >=I
      L     S5T#2S
      SE    T 1
      A     T 1
      =     Q 5.0
      L     C 1
      L     5
      >=I
      R     C 1

P04Star-delta start

Task:

  • I0.0 = start; I0.1 = stop (NC).
  • Q4.0 = line contactor (KM1), Q4.1 = star (KM2), Q4.2 = delta (KM3).

On start, line and star come on. After 5 s, star switches off and delta comes on. Star and delta must never be on at the same time (mutual interlock).

Solution

Line with latching; 5 s on-delay; star = line ∧ ¬T1 ∧ ¬delta; delta = line ∧ T1 ∧ ¬star.

// Line (latching)
      A(
      O     I 0.0
      O     Q 4.0
      )
      A     I 0.1
      =     Q 4.0
// Star time
      A     Q 4.0
      L     S5T#5S
      SD    T 1
// Star
      A     Q 4.0
      AN    T 1
      AN    Q 4.2
      =     Q 4.1
// Delta
      A     Q 4.0
      A     T 1
      AN    Q 4.1
      =     Q 4.2

Frequently asked questions

How do you program a star-delta start in a PLC?

With a latched line contactor, an on-delay timer (SD in English mnemonics) that starts with the line contactor, the star contactor while the time has not elapsed and the delta contactor when it has. Star and delta are interlocked so that they never come on together (exercise P04).

How do you control a tank with a low-level and a high-level probe?

With Set and Reset: Set the pump when the level drops below the minimum and Reset it when it reaches the maximum or the stop button is pressed. Between the two probes the pump keeps its state: this is hysteresis (exercise P01).

Which timer should I use for a staircase light timer?

The extended pulse (SE in English mnemonics, SV in German): the light stays on for the full time even if the button is released, and each new press starts the time again (exercise P02).
