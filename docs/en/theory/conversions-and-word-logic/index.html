Conversions and word logic: BCD, INT, DINT and REAL

How to convert between BCD, INT, DINT and REAL in STL and Ladder, how to round, how to scale an analog input to a percentage, and how to mask and shift bits with word logic.

Conversion

STLLadderConversionNotes
BTIBCD_I3-digit BCD → INT (ACCU1-L)Invalid digit → BCD error (OB121)
ITBI_BCDINT → 3-digit BCDOutside ±999 → OV = OS = 1 and it does not convert
BTDBCD_DI7-digit BCD → DINT
DTBDI_BCDDINT → 7-digit BCD
ITDI_DIINT → DINT (extends the sign)
DTRDI_RDINT → REALAbove 2²⁴ it may lose precision
RNDROUNDREAL → DINT, rounding to the nearestIn the exact case of x.5, the STL manual specifies rounding to even
TRUNCTRUNCREAL → DINT, truncating toward 03.9 → 3 ; −3.9 → −3
RND+CEILREAL → DINT toward +∞3.2 → 4 ; −3.2 → −3
RND-FLOORREAL → DINT toward −∞3.2 → 3 ; −3.2 → −4
INVI / INVDINV_I / INV_DIOnes' complement (inverts the bits)
NEGI / NEGDNEG_I / NEG_DITwo's complement (changes the sign)
NEGRNEG_RChanges the sign of a REAL
CAW—Swaps the 2 bytes of ACCU1-L
CAD—Reverses the order of the 4 bytes of ACCU1

Typical analog scaling (0..27648 → 0..100 %):

      L     PIW 256         // raw value (INT)
      ITD                   // INT → DINT
      DTR                   // DINT → REAL
      L     2.764800e+004
      /R
      L     1.000000e+002
      *R
      T     MD 60           // % as a REAL

Word logic and shifts

InstructionEffect
AW, OW, XOWACCU1-L := ACCU1-L (AND / OR / exclusive OR) ACCU2-L. With a constant (AW W#16#00FF), they operate with the constant
AD, OD, XODThe same with 32 bits
SLW n / SRW nShifts ACCU1-L n bits to the left / right, filling with 0
SSI nShifts ACCU1-L to the right, keeping the sign
SLD n / SRD n / SSD n32-bit shifts
RLD n / RRD nRotates ACCU1 n bits to the left / right
RLDA / RRDARotates 1 bit through CC1
  • Without an operand, the number of positions is taken from ACCU2-LL.
  • After word logic: CC1 = (result ≠ 0), CC0 = 0 and OV = 0.
  • After a shift: CC1 = last bit shifted out.

Example: isolating the low byte of a word with L MW 10 / AW W#16#00FF / T MW 12.

Frequently asked questions

How do I scale an analog input to a percentage?

Convert the value to REAL (ITD and DTR), divide it by 27648 and multiply it by 100. With 13824 on the input, the result is 50.0 %.

What is the difference between RND and TRUNC?

RND rounds to the nearest integer (3.6 → 4) and TRUNC cuts off the decimal part toward 0 (3.6 → 3). RND+ rounds up and RND- rounds down.

With MW10 = −1, why doesn't L MW 10 leave −1 in the 32-bit accumulator?

Because L fills the high part with zeros, without extending the sign: ACCU1 is DW#16#0000FFFF. To treat it as a negative DINT you have to use ITD.
