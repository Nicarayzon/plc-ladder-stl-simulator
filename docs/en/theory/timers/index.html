Timers in Ladder and STL: SP, SE, SD, SS and SF

The five Ladder and STL timers explained with timing diagrams: pulse (SP), extended pulse (SE), on-delay (SD), retentive on-delay (SS) and off-delay (SF). With worked examples.

Timers in Ladder

Boxes and pins (English names, German names in brackets; the ladder diagrams on this site show the German pin names, like the simulator):

PinMeaning
SStart. Depending on the type, it starts on an edge or acts on the level
TV (TW)Time value in S5TIME format
RReset: sets the timer to 0 and Q = 0. It has priority
QTimer status, the same as A T1
BI (DUAL)Remaining time in binary, without the time base
BCD (DEZ)Remaining time in BCD with the time base (S5TIME format)
BoxCoilSTLTypeBehavior
S_PULSE (S_IMPULS)SPPulseQ = 1 from the edge of S, for at most the time TV. If S drops earlier, Q = 0 immediately
S_PEXT (S_VIMP)SEExtended pulseQ = 1 for the whole TV even if S drops. A new edge of S restarts it
S_ODT (S_EVERZ)SDOn-delayQ = 1 when TV has elapsed and S is still 1. If S drops, it stops and Q = 0
S_ODTS (S_SEVERZ)SSRetentive on-delayIt starts with the edge of S and keeps timing even if S drops. Q = 1 at the end and stays at 1 until a reset
S_OFFDT (S_AVERZ)SFOff-delayQ = 1 as soon as S = 1. When S drops, it times TV and then Q = 0. If S returns to 1 while it is timing, it stops and Q stays at 1

Timing diagrams (TV = t):

With TV = 1 s. The signals come from simulating each timer with the simulator’s engine.

Timer coils: with the value S5T#5S below it. The reset is done with a coil on T1, and the status is read with a contact.

Notes:

  • Each timer (T1, T2...) is started in only one place in the program.
  • The value TV is taken on the start edge.
  • The time counts down from TV to 0. The accuracy is that of the time base.
  • If R = 1, the timer stays stopped even if S = 1. When R is released, it does not start again until S has a new edge.

Timers in STL

      A     I 0.0           // start condition (RLO)
      L     S5T#5S          // time value → ACCU1
      SD    T 1             // on-delay (SP, SE, SD, SS or SF)
      A     I 0.1
      R     T 1             // reset
      L     T 1             // remaining time in binary (no time base) → ACCU1
      T     MW 10
      LC    T 1             // remaining time in BCD with time base (S5TIME) → ACCU1
      T     MW 12
      A     T 1             // timer status Q
      =     Q 4.0
InstructionFunction
SP T nStarts as a pulse (S_PULSE)
SE T nStarts as an extended pulse (S_PEXT)
SD T nStarts as an on-delay (S_ODT)
SS T nStarts as a retentive on-delay (S_ODTS)
SF T nStarts as an off-delay (S_OFFDT)
R T nReset if RLO = 1
FR T nEnable: an edge allows a restart without an edge on the start input (rarely used)
A T n / AN T n / O T n...Checks the status Q of the timer
L T n / LC T nLoads the remaining time in binary / in BCD

The start instruction uses the value in ACCU1 at the moment of the edge. That is why the L S5T#… goes right before it.

Worked examples

E12On-delay (SD / S_ODT)

Task: Q4.0 turns on 5 s after I0.0 is activated, and only if I0.0 is still 1. I0.1 resets the timer. MW10 holds the remaining time in binary and MW12 in BCD.

      A     I 0.0
      L     S5T#5S
      SD    T 1
      A     I 0.1
      R     T 1
      L     T 1         // remaining time (binary, in units of 10 ms)
      T     MW 10
      LC    T 1         // remaining time in BCD with time base
      T     MW 12
      A     T 1
      =     Q 4.0

E13Off-delay (SF / S_OFFDT)

Task: fan Q4.1 runs while I0.2 = 1 and keeps running for 3 more seconds after it is switched off.

      A     I 0.2
      L     S5T#3S
      SF    T 2
      A     T 2
      =     Q 4.1

E17Flasher (1 s on / 1 s off) with two timers

Task: while I0.7 = 1, lamp Q4.5 flashes.

Concepts: each timer restarts the other one. Alternative: use a clock memory (see Clock memory: Clock memory).

      A     I 0.7
      AN    T 7
      L     S5T#1S
      SD    T 6         // off time
      A     T 6
      L     S5T#1S
      SD    T 7         // on time
      A     T 6
      =     Q 4.5

Test yourself

Work out the answer before you open the solution.

Q10Time value loaded wrongly

What happens when I0.0 is activated?

      A     I 0.0
      L     500
      SD    T 1
      A     T 1
      =     Q 4.0
Solution

The CPU goes to STOP. 500 = W#16#01F4 is not a valid S5TIME (the digit F is not BCD), so there is a programming error (OB121). While I0.0 = 0 nothing happens, because the value is only evaluated when the timer starts.

Frequently asked questions

What is the difference between the SD and SS timers?

Both are on-delays. SD only turns on Q if S stays at 1 the whole time; if S drops earlier, it stops. SS keeps timing even if S drops and, when it finishes, keeps Q at 1 until it is reset. In German mnemonics they are SE and SS.

Which timer keeps Q at 1 for the whole time even if S drops earlier?

SE in English mnemonics (SV in German): the extended pulse, S_PEXT. The pulse SP, on the other hand, is cut short if S drops early.

Which timer turns Q on as soon as S = 1 and keeps it on for a while after S drops?

SF, the off-delay (S_OFFDT; SA in German): the time starts counting on the falling edge of S.

Why doesn't my timer start again after a reset?

Because it needs a new edge on S. If the start condition was already 1 when the reset ended, it has to go back to 0 and then to 1 again.
