Counters in Ladder and STL: count up, count down and preset value

Up and down counters in Ladder and STL: pins, loading the preset value in BCD, reset, and reading the value in binary or in BCD. With a car park example.

Counters in Ladder

BoxFunction
S_CU (Z_VORW)Up counter: +1 on each rising edge of CU
S_CD (Z_RUECK)Down counter: −1 on each rising edge of CD
S_CUD (ZAEHLER)Up and down counter (it has CU and CD)
PinMeaning
CU / CD (ZV / ZR)Count up / down (on the edge)
SRising edge → loads the value PV
PV (ZW)Preset value in BCD (C#0..C#999)
RReset on the level → value = 0
Q1 if the value is greater than 0
CV / CV_BCD (DUAL / DEZ)Current value in binary / in BCD
  • Range 0..999: it does not go below 0 or above 999.
  • Holding the input at 1 does not count several times: an edge is needed for each unit.
  • Coils: , , (set counter value) and .

Counters in STL

      A     I 1.0
      CU    C 1             // +1 on a rising edge
      A     I 1.1
      CD    C 1             // −1 on a rising edge
      A     I 1.2
      L     C#5             // value in BCD
      S     C 1             // edge → loads 5
      A     I 1.3
      R     C 1             // reset (on the level)
      L     C 1             // value in binary
      T     MW 20
      LC    C 1             // value in BCD
      T     MW 22
      A     C 1             // 1 if value > 0
      =     Q 5.1

Worked examples

E18Car park with 10 spaces

Task:

  • I1.0 = a car comes in; I1.1 = a car goes out.
  • I1.2 loads an initial occupancy of 5; I1.3 resets the counter to zero.
  • MW30 = occupancy. Q5.0 = "FULL" (occupancy ≥ 10). Q5.1 = there is at least one car.
      A     I 1.0
      CU    C 1
      A     I 1.1
      CD    C 1
      A     I 1.2
      L     C#5
      S     C 1
      A     I 1.3
      R     C 1
      L     C 1
      T     MW 30
      L     10          // ACCU2 = occupancy, ACCU1 = 10
      >=I
      =     Q 5.0
      A     C 1
      =     Q 5.1

E19Countdown

Task: I1.4 loads 3. Each pulse of I1.5 counts down by 1. Q5.2 = end of the countdown (value 0). MW32 = value in BCD.

      A     I 1.4
      L     C#3
      S     C 2
      A     I 1.5
      CD    C 2
      AN    C 2         // Q = 0 → value = 0
      =     Q 5.2
      LC    C 2
      T     MW 32

Frequently asked questions

What is the range of values of a counter?

From 0 to 999, because the value is stored as 3 BCD digits. It does not go below 0 or above 999.

Why does the counter only add 1 even if I hold the button down?

Because it counts edges, not levels: to add another unit, the input has to go back to 0 and then to 1.

How do I read the value of a counter in STL?

L C 1 gives the value in binary and LC C 1 in BCD. A C 1 returns 1 if the value is greater than 0.
