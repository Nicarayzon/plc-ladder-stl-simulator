PLC simulator to learn Ladder logic and STL

Automatizacion is a free programmable logic controller simulator for your computer. Program in Ladder (LAD) and Statement List (STL), press RUN and watch the CPU go through the scan cycle, run the timers and switch on the outputs, with no hardware at all. The app is available in English, Spanish and German, and so is the theory on this website.

Features

Simulator features, screen by screen

From the theory and the examples to your own projects with inputs, outputs, memory bits and timing charts. The screenshots show the app in Spanish; in Settings ▸ Language you can switch it to English.

01

Three sections to get started

The start screen brings together what the app includes: the free simulator to write and test your programs, «Aprender» (Learn) with the theory and «Ejemplos» (Examples) with solved programs.

  • When you open it, the app goes straight to the free simulator.
  • The sidebar takes you to each section, the settings and the help.

02

«Aprender»: all the theory, with search

A syllabus organized in chapters, with a table of contents and search: how the PLC and its scan cycle work, memory areas, data types and constants, symbolic addressing, block structure, Ladder, STL and the equivalences between them.

  • Diagrams and tables with the practical consequences that come up most often.
  • Chapters on typical mistakes and exam pitfalls, German and English mnemonics, and a glossary.
  • You can also read it here in English, with interactive examples: Ladder and STL theory.

03

31 worked examples

Examples grouped by topic, from combinational logic to latching, edges and more. Each one opens ready to run, so you can change the inputs and modify it.

  • The KOP label means that the solution is also drawn in Ladder.
  • When you pass its tests, the example is marked with ✔ 100 %.

04

Open an example and watch it run

On the left, the task with the solution in Ladder and in STL and the tests that check it. On the right, the workbench in RUN: the Ladder networks with their toolbar, the inputs and outputs and, below, the logic analyzer.

  • «Comprobar» (Check) runs the tests on your version and «Restaurar» (Restore) goes back to the original.
  • RUN, STOP and MRES; cycle by cycle or instruction by instruction; at ×1, ×10 or ×100.
  • In Ladder, the solid green wire carries power; the dashed blue one does not.
  • NO and NC contacts, coils, parallel branches and an element catalog, also with keys (F2, F3, F7…).

05

Your projects, organized in folders

In the free simulator, each project is a folder with its blocks. You create it in four steps, and then you can add whatever you need.

  • Rename, duplicate and export projects (.json) or their STL source (.awl), and import them on another computer.
  • Everything is saved on your computer: no accounts and no connection.

06

STL editor with «Observar» (Monitor)

The program is written in networks, each with its own title. In RUN, «Observar» shows the RLO, the STA and both accumulators next to each line, and the current value next to each operand.

  • Syntax highlighting, autocompletion and errors marked as you type.
  • German (U, E, A) or English (A, I, Q) mnemonics, with the DE/EN button.

07

Inputs and outputs by hand

Inputs are toggle switches and outputs are lamps that light up. I 124.0–I 125.7 and Q 124.0–Q 125.7 are always visible (E and A with the German mnemonics), plus the ones your program uses, with their symbol if they have one.

  • I 124.0–I 124.7 also with keys 1–8; I 125, with the mouse.
  • Shift + click or Shift + key: a push button, which is 1 only while you hold it.
  • Right-click to change the type of an input or remove it from the panel, and «Añadir entrada» (Add input) for any other address.

08

Memory bits by byte and clock memory

The memory bits used by the program are grouped by byte, with their eight bits in a row; the ones it does not use are dimmed.

  • Enable the clock memory in «Hardware» and its byte appears at the top: each bit oscillates by itself, from 0.1 s to 2 s, with its period below it.
  • Perfect for flashing lights: A M 0.5 / = Q 124.7 makes an output flash with a 1 s period.

09

I/O signals: the timing chart

In the bottom panel, a timing chart draws how the inputs, outputs, memory bits, timers and counters you choose change over time. Here, M 0.2 is the 0.4 s clock memory bit.

  • «Seguir» (Follow) in real time, zoom, and A and B cursors to measure Δt.
  • A trigger to freeze the right moment, and export to CSV or PNG.
  • In the same strip: messages, the STL generated from the Ladder, the cycle trace and the variable tables you dock there.
  • The ⧉ button opens it in another window, so you can move it to another monitor.

10

Variable table: monitor and modify

Right-click OB1 → «Insertar nuevo objeto» → «Tabla de variables» (Insert new object → Variable table) to open VAT_1 in a window inside the app, which stays on top while you keep programming. The glasses read the CPU values live.

  • Each row with its format: BOOL, BIN, HEX, DEC, REAL, S5TIME, TIME or CHAR, only the ones that fit the operand.
  • «Valor de forzado» (Modify value) to write a value once or keep it forced on every cycle.
  • It can be moved and minimized, or docked at the bottom next to the signals. It is saved with the project.

Questions

Frequently asked questions

What is a PLC (programmable logic controller)?

A PLC (programmable logic controller) is the industrial computer that controls machines and installations: it reads push buttons and sensors through its inputs, runs the program in a cycle that repeats without stopping, and drives motors, valves or lamps through its outputs. This simulator reproduces that behavior on your computer.

What is the difference between Ladder and STL?

They are two ways of writing the same program. Ladder (LAD, called KOP in German) is graphical and looks like an electrical diagram. STL (Statement List, called AWL in German) is text, closer to how the CPU works. In the app you can see the STL generated by each Ladder network.

Do I need a real PLC to practice?

No. The simulator acts as the CPU: you operate the inputs with switches or the keyboard, you see the outputs, memory bits, timers and counters, and you can step through the program instruction by instruction. When you work with a real PLC, you will arrive with the program already tested.

macOS says it cannot open the app

The app is not signed by Apple. The first time, open System Settings → Privacy & Security and click «Open Anyway» next to the Automatizacion warning. You can also run this in Terminal:

xattr -dr com.apple.quarantine /Applications/Automatizacion.app
Windows shows a SmartScreen warning

The executable is not signed by Microsoft. Click «More info» and then «Run anyway».

Does it work on Linux?

There is no native Linux version, but the Windows one works with the Wine compatibility layer: download the .exe installer or the portable .zip and open it with Wine. One user runs it with this setup:

  • DistributionArch Linux
  • KernelLinux 7.2.9-arch1-1
  • Shellbash 5.3.20
  • Wine11.19
Where are my projects saved?

On your computer, never online: on macOS, in ~/Library/Application Support/Automatizacion; on Windows, in %APPDATA%\Automatizacion. They are kept when you update the app, and you can export each project as .json or as .awl source.

How do I update to a new version?

Since version 0.22.0, the Automatizacion ▸ Buscar actualizaciones… menu (Check for updates; on Windows, Ayuda ▸ Buscar actualizaciones…) tells you if there is a new version and opens its page. You can also download it from here. On macOS, quit the app with ⌘Q and drag it to Applications again (Replace). On Windows, run the new installer: it replaces the previous one without touching your projects.

Does it work on a Mac with an Intel processor?

No. The macOS version is built for Apple Silicon (M1, M2, M3 and later).

What language is it in?

In English, Spanish and German since version 0.25.0: the interface, the menus, the theory and the 31 examples. The first time it opens in the language of your system, and you can change it in Settings ▸ Language (the change applies the next time you open the app). Code can be written with English or German mnemonics in any of the three languages, and the theory on this website is also available in English and German.

Is it free?

Yes. It is open source under the MIT license: no ads and no accounts. It works offline; it only connects to the internet if you ask it to check for updates.
